- 帧号落点：输入时间（或逐帧操作）跳转后，元素呈现帧的媒体时间与按帧时间戳索引算出的时间一致，且经呈现帧回调核实；VFR 与非零起点按时间戳处理。
- ASS 字幕（含内封附件字体）在 MKV 样本上用 JASSUB 绘制，样式字体缺失的中文 ASS 用随包的开源中文字体画出，不同的字是不同的字形；AC3 音轨需要播放副本，合成短样本的副本构建耗时 440 ms。
- 漫画：目录、CBZ、图片 PDF 三类样本在窗口里逐页翻页并重启恢复。
- 窗口实测耗时：漫画翻页 p50 28 / p95 29 ms；视频首帧 p50 46 / p95 483 ms（7 个样本）；帧号跳转落点 p50 29 / p95 32 ms（21 个样本）。
- 隐藏窗口不呈现帧，所以 media 阶段把窗口显示在屏幕上（不抢键盘焦点）；渲染进程崩溃会被记为该样本失败并重载继续，不会静默通过。

## 依赖与选型

- **bot 路线（LOOP-03，外部启用在 ACT-04）**：Dependabot 原生 npm/Actions（每周，minor/patch 分组，major 单独审查，无自动合并）；PR 设计依据与模板检查；复核既有 DCO App；可选的建议性 AI review（先手动试跑，不向 fork 暴露 secrets）；发布前评估 CodeQL/依赖审查与签名。优先复用 GitHub 原生能力，不启用 stale、欢迎或自动标签。

<a id="defaults"></a>
## 实现中采用的默认

这些是 Agent 按推荐值实现的可逆默认，用户想改就说（需要用户拍板的另在[用户待办](../../USER-ACTIONS.md#decisions)）：

- 应用默认打开“总览”；漫画默认阅读方向从右到左（设置可改）；“移出资源库”没有提供，扫描到的不可用文件只标记，不删除；文件的记录（笔记、书签、录音、对话）一律保留，作品里有用户写的内容（词典、术语、改过的字段、笔记、对话）时，作品在文件都不在后也保留，同指纹文件回来后自动重新关联（A-67）。
- 录音：F9 按住录音、F8 切换录音（只在应用内有效，不注册全局热键）；录音期间视频降到约 30% 音量（`DUCK_FACTOR = 0.3`）；默认保留音频；边界余量 300 ms。
- 视频：换到非默认音轨而画面可播时走重封装（不重新编码，原文件不动，副本在缓存可删）；“改用播放副本”开关在播放器状态区；自动下一集默认关，播放器里没有“下一集”按钮；短按方向键跳 5 秒，按住 → 超过 300 ms 按临时倍速（默认 2 倍）播放，按住 ← 连续快退（每秒约退 4 秒），鼠标右键只是菜单（A-71）。ASS 字幕的默认字体是随包的开源中文字体（Noto Sans CJK 简体中文子集，不含韩文），本机字体只在随包字体不可用时补位；字幕轨选定后画一次当前帧，暂停的画面也能立即看到字幕。
- Agent：`spoilerGuard` 默认关闭，开启后字幕窗口不超过已看进度的前沿；字幕窗口默认不超过当前位置，用户显式放宽（`subtitleAheadMs`）只对该次任务有效；在线元数据搜索需要模块启用且任务授权包含该命令，默认关闭；视觉/OCR 路由未配置或模型不支持图像时请求返回缺少能力，不声称已理解。
- 笔记只能在打开的资源和作品主页里写，其他页面只能问 Agent；TXT 和 PDF 以文件名（扫描时为文件夹/文件名）作为书名，EPUB 与 MOBI 用书内书名。
- 后退与前进只记停留过片刻的页面，匆匆经过的页面不进历史；关闭左栏的已打开资源只是移走它，资源会话与对话保留，再次打开恢复同一会话和位置；左右栏的宽度按模式记住，窄窗时先把侧栏收成浮层。
- 资源库入口：关联到同一个 Bangumi 条目、同一媒介的作品合成一个入口，只合并显示、不合并数据，取消关联就拆开；入口里每个作品是一个版本，默认用上次的版本，切换时同一集内按比例对齐位置；同一个作品里同一集的两个文件仍是两个资源，不拆成版本（Q-25）。下载目录在第一次用到时登记为资源库路径（A-69）。
- 漫画滚轮：单页与双页一次手势翻一页，放大到能滚动时先滚页面、到边缘再翻页，Ctrl 加滚轮以指针为中心缩放（25%—400%），条漫模式滚轮正常滚动（Q-24）。
- 带底栏的页面里，悬浮胶囊停在右上角、标题栏之下，窄窗下阅读器顶部的标题裁切而不是重叠；60 秒内连续的视图设置变更在日志里合并成一行；日志保留 180 天或 5 万条。
- 漫画路径对只设置所有者密码的 PDF 不再预先拒绝，需要打开密码的仍以 `UNSUPPORTED_FORMAT` 拒绝；加密的压缩包、EPUB 与 MOBI 照旧拒绝。
- 带图片的 Agent 任务把图片字节（最多 4 张，每张 ≤ 1.5 MB，每任务 ≤ 4 MB）冻结在运行快照里，保证重试与继续发送同一画面；列表不读取，资料包不含运行记录，完整备份包含（[LOOP-05](#loop-05)）。
- 快捷任务是设置里可配置的提示词模板；占位符为作品、作者、当前位置、选区、字幕窗口、用户输入，未知占位符保存时拒绝，缺内容时渲染为空并在消息里说明；运行中只挡会发送的快捷任务，附图照常可用但不进入正在运行的任务。
- 作品/资源的“媒介类型”属于资源，导入时系统给出建议、用户可改，改类型不新建修订、不搬迁锚点。
- 创作：项目会话只在项目的材料范围内读写资料；白板与导图的撤销历史属于 Profile，不进项目包；嵌入默认“跟随原对象”，快照需要主动选；笔记保存时不拒绝形成循环的嵌入（不丢用户已输入的内容），读取时判为“循环”并只提供移除；文稿版本超过 100 条时先清掉没有标签的最旧版本。
- 材料搜寻：只取用户给的那一个网址，不爬取链接、不执行页面脚本、不带 cookie；响应最多 2 MiB、15 秒、5 跳；不内置网页搜索引擎。
- 语义检索：默认关闭；默认切法 `paragraph-600`；只用用户配置的 Embedding 连接，不回退到别的连接；不同模型的向量永不比较。
- 粗剪：起点退到请求处或之前最近的关键帧，终点进到请求处或之后第一帧，实际区间永远包含请求区间；成片的容器取第一个片段的容器；核对不符时什么都不留下；视频模块关闭不影响序列的编辑与导出。
- 插件与下载：只收签名可信的包；权限逐项确认，升级带来的新权限重新确认；升级后的新版本无法启动时自动退回上一版本；卸载默认保留插件的数据；下载完成即停止做种，做种默认上传比例 1.0；引擎默认加入公共 DHT，本地发现、UPnP、NAT-PMP、WebRTC、web seed、uTP 关闭；每个任务的最严限速应用于整个引擎；磁力链接不在任何视图、通知与日志里出现。

## 验收记录方式

AT-01 以来的验收用例不按一次技术报告或一次总体人工反馈全量改为 passed；已测范围以各报告具体子场景和用户确认范围为准。POC passed 只指注明的原型子集。设备项只影响依赖它的录音与播放验收，不能把待开发缺口转交用户测试。

状态统一使用 not-run、running、passed、failed、blocked；blocked 必须注明阻塞与负责人，passed 必须限定实际版本和范围。变更使旧证据失效时保留历史，把当前受影响范围改为待验证。阶段报告脚本（`node scripts/stage.mjs report`）只核对证据完整且指纹匹配，`productAcceptance` 固定为 not-run，不计算阶段验收。
