## 2. A 已核对的现场

- **外壳。** 两种模式是两个独立工作区（A-77）：`apps/desktop/src/renderer/lib/mode-view.ts` 的 `ModeView` 按模式保存页面、作品页、项目视图、已打开的资源、笔记与后退前进历史；`ShellPreferenceSchema`（`packages/contracts/src/reading.ts`）按模式保存左右栏的宽度与显隐；`shell.tsx` 里每栏有自己的 36 px 栏顶，模式切换在左栏栏顶。

- **进度。** `progress` 的主键是（`resource_id`、`resource_revision_id`），全局一份；读它的地方包括阅读器恢复、书架百分比、“最近打开”排序、防剧透的已看前沿、Agent 的 `progress.get`。

## 4. 设计

### 4.1 工作上下文

工作上下文（下称上下文）是“在哪里工作”：一个项目，或“最近”。上下文的编号是项目编号，“最近”用固定值（数据库里为空字符串，接口里为 `null`）。下面这些都按上下文分开：标签与布局（W2、W3）、对话（W6）、阅读观看进度（W5）、停靠栏显示哪段对话。资源、作品、笔记、录音、截图、书签、词典与项目对象都不分上下文，仍各只有一份。

启动时回到上次所在的上下文。项目被归档时，它的标签与布局保留但不在侧栏常驻（从项目总览打开）；项目被删除时，它的标签与布局一起删除，它的进度记录删除，对话按现有的删除规则处理。

### 4.2 布局

> 图标栏、侧栏、搜索与设置已按 2026-10-23 的反馈改写（A-99—A-101），以[第 12 节](#feedback-shell)与交互设计第 2 节为准；本节其余内容照旧。

从上到下、从左到右（像素是默认值，B 可以按设计规则微调并在设计文档里写明）：

- **顶部一行**，高 36 px，横跨窗口：侧栏开关、后退、前进（作用于获得焦点的标签）、菜单（文件、编辑、视图、帮助）；中间是拖动区；右端依次是调试面板开关与应用绘制的窗口按钮（A-91 不变，Q-32 的代价不变）。原左上角的“≡”菜单取消，内容并入四个菜单：
  - 文件：新建项目、新对话、新标签页、重新打开关闭的标签、关闭标签、导入资料包、导出资料包、退出；
  - 编辑：撤销、重做、剪切、复制、粘贴、全选、查找；
  - 视图：布局（单栏、左右两栏、三栏、四宫格）、显示侧栏、显示对话栏、窗口全屏、屏幕全屏、调试面板；
  - 帮助：键盘快捷键、日志与资料位置、关于。
- **图标栏**，宽 48 px：资源库（总览）、项目总览、搜索（材料搜寻与全文搜索）、记录（笔记、录音、对话、日志、使用记录）、下载（安装了下载插件时）；设置固定在底部。点开都在获得焦点的栏里打开对应的标签；已经有这个标签就切过去。悬停显示名称。
- **侧栏**，默认 260 px，可调（200—400）、可隐藏：顶部是“MANGA”与搜索按钮；“新对话”（在当前上下文里）；“新建项目”；“项目”分组列出未归档的项目，当前上下文高亮，展开后按最近活动列出项目里的对话（默认 5 条，多的收进“更多”）；“最近”分组列出项目之外的对话。点项目名切换到该项目；点对话切到它所在的上下文并把对话作为标签打开。右键菜单：项目可以重命名、归档、打开项目主页；对话可以重命名、移到某个项目、删除（确认后走 A-89 的删除）。
- **主区**：标签页加分屏（4.3、4.4）。
- **停靠栏**，默认 360 px，可调、可隐藏：Agent 对话（4.6）。对话标签获得焦点时停靠栏自动收起，焦点离开后恢复。

窄窗（宽度低于侧栏 + 主区最小宽度 + 停靠栏时）依次把停靠栏、侧栏收为浮层；浮层由按钮或快捷键打开，Esc 关闭并把焦点还回去（沿用 UI-06 的现有行为）。

### 4.3 标签页

**标签类型。** 资源库（总览、小说、漫画、动漫与作品主页在同一个标签里导航）、阅读器（小说、漫画、动漫，按资源）、笔记、项目主页、白板、导图、文稿、粗剪、对话、搜索、记录、下载、设置、调试面板以外的其他现有页面。调试面板保持浮层。

**打开规则。**

- 普通点击：在获得焦点的栏里打开；同一个上下文里已经有同一目标（同一资源、同一对象、同一设置）的标签时切到它，不重复打开（Q-33 第 1 项）。资源库标签例外：可以有多个。
- 中键或 `Ctrl` + 点击：在获得焦点的栏里新开一个标签，不切过去。
- 阅读器标签从资源库标签打开时，资源库标签保留在原处。
- 每个标签有自己的后退前进历史（资源库标签里从总览到作品主页的导航、设置标签里的分页、笔记标签里的跳转）；顶部一行的后退前进与鼠标侧键作用于获得焦点的标签。原来全应用一份的页面历史（A-70 的那部分）取消。
- 关闭标签只是关闭视图：会话、进度与草稿保留；“重新打开关闭的标签”恢复最近关闭的 10 个，回到关闭前的位置。
- 打开前的检查（A-86）照旧：不能打开的资源不建阅读器标签，弹出现有提示。

**标签的外观。** 图标表示类型，标题是资源或对象的名字（截断时悬停显示全名）；正在播放的视频与正在录音的标签有标记；运行中的 Agent 任务在对话标签上有标记。标签条可以横向滚动，右端有“+”（新标签页：打开资源库标签）。

**标签的状态。** 每个标签保存自己的视图状态（阅读器：位置、缩放、字幕轨、倍速、阅读设置；页面：滚动位置与筛选），随上下文的布局一起保存。

### 4.4 分屏

- 四种布局：单栏、左右两栏、三栏、四宫格（2×2）。从“视图 › 布局”与主区右上角的布局按钮选择；`Ctrl+\` 在单栏与左右两栏之间切换。
- 切换布局时，已有的标签按顺序分到各栏；减少栏数时多出的标签并入最后一栏，不关闭。
- 标签可以拖到另一栏，或拖到某栏的边缘形成新栏；总栏数上限 4，超过时不形成新栏。
- 分隔条可拖动，双击均分；最小栏宽 320 px。
- 获得焦点的栏有一条细的强调色上边；点击栏内任意处或 `Ctrl+1`—`Ctrl+4` 切换焦点。
- 键盘快捷键（阅读器的 F、W、S、D、R、方向键、空格等）只作用于获得焦点的栏；全屏（窗口全屏、屏幕全屏）只显示获得焦点的标签。
- 窗口放不下当前布局时只显示获得焦点的栏，栏的上方出现切换其他栏的按钮；窗口变宽后恢复原布局，保存的布局不因此改变。

### 4.5 阅读器实例与资源占用

- 阅读器的状态与组件属于标签：`useNovel`、`useComic`、`useVideo` 改为按标签实例化（或等价的按标签控制器），不再挂在 `App` 顶层。不同标签的同一资源是不同实例，各自报告位置。
- **挂载策略。** 在某一栏里可见的标签挂载并活动。不可见的阅读器标签里，最近用过的两个保持挂载并暂停，更早的在保存状态后卸载，切回来时从保存的位置重新载入（Q-33 第 6 项）。这同时处理了 [LOOP-19](status.md#loop-19)。轻量页面（资源库、设置、项目页面）不可见时可以卸载，切回时恢复滚动位置。
- 视频标签在不可见时暂停；可见但不在焦点的栏里时继续按用户的操作播放，不自动暂停。录音期间的降低音量作用于所有正在播放的视频。
- 弹幕、截图、加入粗剪与区域引用都属于所在的标签。
- 录音（悬浮胶囊与停靠栏的麦克风）绑定开始录音时获得焦点的阅读器标签，位置事件只来自这个标签；录音期间切换焦点不改变绑定。

### 4.6 右侧停靠栏与对话

对话属于上下文。停靠栏显示哪段对话，按获得焦点的标签决定（Q-33 第 5 项）：

| 获得焦点的标签 | 停靠栏显示 |
| --- | --- |
| 阅读器（资源）、作品主页、笔记 | 这个资源、作品或笔记在当前上下文里的对话（沿用 `resource`、`work`、`note` 三类会话），第一次在这里用时建立；笔记气泡与提问照旧带着标签的位置与选区 |
| 项目主页、白板、导图、文稿、粗剪 | 项目当前的对话（`project` 类） |
| 资源库、搜索、记录、下载、设置 | 当前上下文当前的对话：“最近”是 `shared` 类，项目里是项目当前的对话 |
| 对话标签 | 停靠栏收起（同一段对话不显示两遍） |

- “新对话”在当前上下文里开启：“最近”里建 `shared` 类，项目里建 `project` 类（一个项目可以有多段对话，当前的那段记在元数据里）。原来的“开启新对话”与历史保留：停靠栏顶部可以开新对话、打开这段对话所在上下文的历史。
- 项目命令只给项目上下文里的对话（A-73 的范围不变）；“最近”里的对话没有项目命令。
- **加入项目材料（Q-33 第 2 项）。** 在项目上下文里打开资源、写笔记、录音、截图时，把资源（以及新建的笔记、录音、截图）加入该项目的材料，`project_materials` 记来源为“自动”；用户可以从材料里移除，移除后在这个项目里再次打开不再自动加入。项目的 Agent 因此能读到在项目里打开过的资源。“最近”里不加入任何项目。
- AGENT-06 的独立交流页就是对话标签；“设置 › 记录 › 对话”的筛选从“按模式”改为“按项目”（含“最近”）。

### 4.7 进度按上下文（A-96）

`progress` 增加上下文：每个上下文对每个资源修订各有一份最后位置、已消费区间与完成状态。读进度的地方按用途分三类，B 逐个核对所有读 `progress` 的代码（不只是下面列出的）并归类，写进报告：

| 用途 | 取哪份进度 |
| --- | --- |
| 阅读器恢复位置、保存位置、`progress.set` / `progress.get`、已读区间的绘制、续读续看、手动标记与重置 | 当前上下文的 |
| 资源库卡片的百分比与“已读/已看”标记、“最近打开”排序、作品主页的继续阅读 | 所有上下文里最近一次的，卡片注明来自哪个上下文（当前上下文的不注明） |
| 防剧透的已看前沿、Agent 的“已看范围”、字幕窗口不超过已看位置 | 所有上下文里最远的（Q-33 第 4 项） |

- 在一个上下文里第一次打开别处看过的资源：从头开始，标签顶部出现一行提示“在「<上下文名>」看到 <位置>，跳过去”，可以关闭；跳过去后按当前上下文记录（Q-33 第 3 项）。
- 书架状态（想读、在读、已读、搁置）仍属于作品、不分上下文；第一次打开时自动变为“在读”的规则不变。
- Agent 任务的快照记下上下文编号；`progress.get` 给 Agent 返回当前上下文的进度，同时给出最远位置供防剧透。

## 6. 界面要点

- 视觉沿用现有的白灰粉主题与 token；新增的图标栏、标签条、分隔条、焦点栏的强调色都用 token，深浅主题都要有。标签条高 32 px 左右，与顶部一行区分层次；不用圆角卡片包住各栏。
- 参考截图只用来定布局与信息结构；仓库文件不写它来自哪个产品。
- 空状态：新上下文的主区是一个资源库标签；空项目的侧栏下显示“还没有对话”；“最近”为空时同样。
- 拖动标签时显示落点（栏内、栏边形成新栏）；超过 4 栏时栏边不出现落点。
- 所有新控件有可访问名称；标签条、侧栏树、图标栏都能用键盘到达；焦点在分屏之间移动时有可见的焦点环。

## 7. 样本、门禁与基准

**样本。** 全部合成：沿用 `dist/samples/media/` 的视频、漫画与小说；新增 v11 资料的生成器（第 5.3 节 W5），放在测试夹具或生成脚本里，不入库真实数据。

**窗口观察（打包烟测，新增，必需）：**

| 观察 | 内容 |
| --- | --- |
| `workspace-frame` | 宽、窄、矮三种窗口下顶部一行、图标栏、侧栏、主区、停靠栏的位置与命中测试；没有模式切换 |
| `workspace-menu` | 四个菜单逐项可用 |
| `tabs-open-restore` | 从资源库打开三种阅读器与项目对象，标签标题正确；同一资源不重复；关闭后重新打开回到原位；重启后恢复 |
| `split-presets` | 四种布局切换，标签不丢 |
| `split-move-video` | 播放中的视频移到另一栏与新栏后继续播放、时间连续、没有重新加载 |
| `split-focus-keys` | 快捷键只作用于焦点栏；焦点栏的窗口全屏 |
| `context-switch` | 两个项目与“最近”之间切换，标签与布局各自恢复 |
| `same-file-contexts` | 同一集在两个项目与“最近”里打开，各自的进度互不影响，资源库卡片注明来源 |
| `dock-follows-focus` | 停靠栏按第 4.6 节的表切换 |
| `migrated-profile` | 用 v11 合成资料启动，对话与已打开的资源都在第 4.8 节规定的位置 |

删除的观察（模式相关，例如 `modes-two-overviews`）在报告的迁移映射里逐个写明由哪项新观察替代。上一阶段的其余必需观察保持必需。

**基准（新增门槛）：**

| 指标 | 门槛 |
| --- | --- |
| 切换标签（目标已挂载）到内容可见，p95 | ≤ 100 ms |
| 切换上下文到焦点标签可见（标签已挂载 / 重启后首次恢复），p95 | ≤ 300 ms / ≤ 2000 ms |
| 四宫格（两路视频其一播放、漫画、文稿）播放时晚到帧的占比 | ≤ 2% |
| 四宫格相对单栏视频的应用工作集增量 | ≤ 600 MiB |
| 打开 10 个阅读器标签并轮流切换后，挂载的阅读器数 | ≤ 可见栏数 + 2 |

现有门槛全部保留，目标与测量方法不改。跑基准前确认机器空闲、启动它的应用在前台（[LOOP-13](status.md#loop-13)）。
