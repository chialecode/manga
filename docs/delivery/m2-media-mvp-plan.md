**阶段完成后用户能做到：**

1. 导入小说（已有）、漫画（PNG/JPEG 图片目录、CBZ、漫画 PDF/EPUB/MOBI）和动画（单个视频或剧集目录）。一个目录可作为一部作品导入，按卷、话、集排序。
2. 在“小说 / 漫画 / 动漫”资源页按参考图浏览封面：按媒介分区、按书架状态筛选、搜索、排序、网格/列表切换。资源总览包含漫画、视频、录音和封面的占用。
3. 封面默认从文件提取，也可在线搜索 Bangumi，人工确认关联后把封面和资料下载到本地，还能换封面、锁定、取消关联。资料由 Bangumi 和文件内置资料（EPUB OPF、CBZ 内的 ComicInfo.xml、视频容器标签）合并，每个字段可见来源。作品详情显示 Bangumi 关联作品（续集、前传等）和本库中标签相近的作品，剧集列表可带 Bangumi 集标题。断网或停用元数据模块后，已保存的封面和资料照常显示。
4. 打开小说（新增双页、字体选择和五种背景）、漫画阅读器和动画播放器，完成常用控制。HEVC 在没有硬件解码的设备上可生成本地播放副本，AC3/DTS 等音轨可转换后播放。可在三种媒介上创建带来源的笔记（文本范围、页面区域、时间区间），跳转并返回来源；进度在重启后恢复。
5. 在三种媒介中按住或切换录音；翻页、暂停、倍速、跳转和切换资源都会被记录，后台录音时悬浮框显示状态。配置 ASR 后，本地先筛除无人声区间再转写，每段文字对应录音当时的小说位置、漫画页或动画时间；可用模型整理成笔记；可选择保留或不保留音频；用气泡或分段进度条回顾并跳回来源。未配置 ASR 时，保留模式的录音先保存，配置后再转写。
6. Agent 在每个资源会话中拿到对应上下文（位置、选区或区域、字幕窗口、作品资料、笔记、转写）。配置了视觉/OCR 路由时，可读取漫画区域和视频帧；未配置时明确提示缺少能力。界面与 Agent 调用同一套命令。
7. 漫画阅读、视频播放、元数据和录音模块可分别停用；停用后数据保留，重新启用后恢复。

## 4. 数据与契约

schema 从 v6 升到 v7，整个阶段只发布一次迁移。沿用既有迁移模式：迁移前备份，DDL 与版本发布在同一事务，中断后可重试；只用合成旧库验证，真实 Profile 迁移 not-run。下表是必须满足的语义，具体列名与拆表由 B 决定并写入领域模型。

| 对象 | 必须满足 |
| --- | --- |
| 媒介类型 | 资源有 `novel` / `comic` / `video`（保留 `audio` / `file`）。导入时由用户选择，按内容给默认建议（例如全图片的 EPUB/PDF 建议为漫画），之后可改。改类型不新建修订、不搬迁锚点；已有锚点按定位类型在支持它的阅读器中解析 |
| 作品与序列 | 一部作品可含多个资源；资源有序号标签（第 N 卷/话/集、SP）和排序键。目录导入为一部作品，子文件或子目录按自然排序（`Intl.Collator` 数字排序）并结合文件名解析排序。资源可移到另一部作品。重复导入同一指纹沿用 M1b 的重复识别 |
| 书架状态 | 作品级 `none` / `wishlist`（想读）/ `reading`（在读）/ `finished`（已读）/ `on_hold`（搁置），用户可改。默认规则：首次打开且状态为“无”或“想读”时改为“在读”；不自动标“已读”（Q-12 可调整）。与 Progress 的完成状态分开保存 |
| 作品摘要 | 列表查询返回：投影后的标题与作者、媒介、书架状态、封面缩略图句柄、最近打开的资源及其序号标签、该资源进度百分比、已消费的集/话数、是否已关联外部条目。按游标分页，total 为完整匹配数（沿用 M1b 分页规则） |
| 封面 | 来源分三类：从文件提取、Bangumi 下载、用户指定。Bangumi 与用户图片的原图存入附件分区（权威数据，进入备份和资料包）；从文件提取的封面和所有缩略图存入缓存分区（可重建）。作品记录当前选用的封面；用户选择或锁定后，自动刷新不得替换。原图按内容哈希命名，数据库只存引用，不存 BLOB；无引用的封面文件按附件清理规则处理 |
| 提供者实例与外部关联 | 提供者实例至少两个：`bangumi`（在线）和 `local-file`（文件内置资料）。复用 `work_links` 作为外部身份：provider、namespace `bangumi:subject`、外部 ID（字符串）、条目类型、关联状态、确认时间、匹配依据。一部作品可关联一个 Bangumi 条目；歧义候选不自动关联 |
| 元数据快照 | 记录抓取时间、来源 URL、接口版本和所用字段：`name`、`name_cn`、`summary`、`date`（保留精度）、`platform`、`eps` / `volumes`、`images`、评分（分值、人数、站点量纲、抓取时间）、`tags`（前若干个）、infobox 中的作者/作画/制作公司；关联条目（关系类型、ID、名称、类型）；集信息（序号、标题、播出日期）。不保存整份原始响应 |
| 字段投影 | 优先级沿用[外部扩展 4.3](../design/external-providers-and-acquisition.md#43-多源组合规则)：用户覆盖/锁定 → 已确认关联的在线来源 → 文件内置资料 → 文件名。源中缺失的字段不清空本地已有值；评分不做跨站平均。每个字段的候选与当前选择可解释 |
| 相关作品 | 由两类有来源的结果组成：已关联条目的 Bangumi 关联条目（标注关系类型，本库已有的标为“已在书架”），以及本库中标签重合度高的作品。只在作品详情和右栏显示，不调用模型 |
| 漫画页面清单 | 修订载荷记录页面序列：稳定 pageId（来自容器条目路径，或页号加内容哈希）、尺寸、哈希、是否跨页。图片字节按需从原件读取（目录文件、CBZ 条目、PDF 渲染、EPUB 条目、MOBI 记录）；为显示生成的缩小图或切片放缓存。页面区域坐标始终相对原始页面，取值 [0, 1] |
| 媒体探测 | 每个视频修订保存探测结果：容器、时长、起始时间、时间基、各流（编码、profile、位深、语言、标题、默认）、字幕轨、附件字体、关键帧位置、所用工具版本。帧时间戳索引（显示顺序的 pts 列表）存缓存分区，可重建 |
| 播放副本 | 缓存分区中的派生文件，记录对应的原件修订、生成原因（无硬件 HEVC、不支持的音轨、所选音轨重封装）、编码器与版本、时间戳校验结果。锚点、进度和帧号始终基于原件时间线；副本删除后可重建，不影响任何引用 |
| 进度 | 漫画：最后 pageId、已读页区间。视频：最后时间、实际播放形成的已消费时间区间（拖动跳过的部分不计入）。作品级进度由资源进度汇总，不另存一份 |
| 锚点 | 漫画用 `image` 定位（pageId + 可选区域），视频用 `temporal` 定位（startMs/endMs，可附 trackId）；解析状态沿用六种结果。修订指纹不同的视频不复用时间锚点 |
| 录音 | 按[领域模型第 9 节](../design/domain-model.md#9-语音采集与位置映射)实现 CaptureSession、CapturePositionEvent、转写段与整理产物。位置事件覆盖：小说的修订与语义位置/选区；漫画的 pageId 与清单修订；视频的原件时间、播放/暂停、倍速、跳转和换集；资源切换。采集时钟用单调时钟。音频状态分为长期保留、处理暂存、已清理；会话、转写和锚点不依赖音频文件仍然存在 |
| 图像材料 | 漫画区域裁剪和视频帧是临时材料，附带来源定位与提取方式；只有用户保存时才成为附件 |
| 资料包与备份 | 新表、封面附件、录音附件、关联、快照、候选和位置事件纳入完整备份与资料包往返；作品 ID 重映射时封面、关联与录音锚点一起重映射；冲突规则沿用 M1b（不相容组合在写入前拒绝） |

新增命令全部经同一应用服务、Zod 校验和授权，Agent 与界面共用。至少包括：

- 作品：列表与详情、目录导入为作品、设置媒介类型、移动资源、设置书架状态、设置字段覆盖。
- 封面：列表、选择、锁定、从图片设置。
- 元数据：搜索、候选、关联、取消关联、刷新、相关作品。
- 漫画：页面清单、页面读取句柄。
- 视频：探测、字幕列表、音轨列表、帧索引查询、生成或取消播放副本。
- 进度：写入页、写入时间。
- 录音：开始、停止、状态、转写、重试、取消、整理、保留/清理、回顾查询。
- 材料：区域图、视频帧、字幕窗口。

网络与写操作的 Agent 授权见 P7。

**本地媒体协议。** 注册特权 scheme（standard、secure、stream、supportFetchAPI），URL 只含不透明句柄。句柄由主进程按“资源/修订/条目或流/会话代次”签发，模块停用、会话关闭或代次变化后失效。协议处理 Range（206/416）、Content-Type 和取消；不接受路径参数，不能越出原件或缓存文件范围。封面、缩略图、漫画页面、视频、播放副本、提取出的字幕与字体、录音回放都经此协议提供；CSP 增加对应来源。

## 7. 样本、网络与验证边界

1. 全部行为测试使用合成样本、独立临时 Profile、本地假 Bangumi 服务（按官方 OpenAPI 结构构造的合成条目与图片）和可控的假 ASR/LLM/视觉适配器，不依赖外部网站或模型是否可用。
2. Bangumi 真实契约测试：只读、无凭据、每次运行不超过 10 个请求，默认关闭，用环境变量显式开启。只核对响应结构、UA 被接受和图片可下载，不把条目内容写入仓库。网络不可达（例如未配置系统代理）记 blocked，不算产品失败。不进入 CI。
3. ASR 真实契约测试：按 A-28/A-29 读取忽略的本地测试配置，只发送 P0 生成的合成 TTS 语音，每次运行不超过 10 个请求，默认关闭。缺配置时记 not-run，不向用户索取。LLM 整理与视觉/OCR 的真实调用不在已授权范围内，按 ACT-05 处理：未授权时记 not-run。
4. 不复制真实漫画、动画、小说或录音进仓库与证据。A-23 授权的本地真实资源根只可用于开发者本机的只读打开试验，结果不写具体文件名和路径。

### 14.5 数据与契约

- **库结构 v8**：按[领域模型 11.1](../design/domain-model.md#111-建议逻辑表)的“版本 7 → 8”表实现，只增不改；迁移前备份，DDL 与版本发布在同一事务，中断后可重试。用合成 v6 与 v7 库各验证一次（v6 → v8 一次完成且只备份一次）。
- **新增或调整的命令**（名称可调整，经同一应用服务、Zod 校验与授权）：资源库路径的列出、添加、修改、移除；扫描的开始、取消、状态；作品主页数据（可扩展 `works.get`）；按 ID 或链接解析条目、关联预览、刷新预览与确认应用；角色与制作人员查询；快捷任务的列出、保存、删除、排序、恢复默认；日志查询；用量查询；会话消息流查询；笔记软删除与恢复；上下文调试数据。
- **授权**：资源库路径的添加与移除只开放给界面，不开放给 Agent（模型不能提供路径，见[资料库模块](../modules/library.md)）；Agent 可以查询扫描状态与日志。关联与刷新沿用 M1a 的写操作确认；快捷任务不改变授权。
- **ID 与链接解析**：接受纯数字 ID、`subject/<ID>`、`https://bgm.tv/subject/<ID>`、`https://bangumi.tv/subject/<ID>`、`https://chii.in/subject/<ID>`（可带 `www.`、末尾斜杠、查询串与片段）；其他主机、非数字 ID、`character/`、`person/` 等路径拒绝并说明。
- **日志条目**：时间、操作者（用户、Agent 及运行 ID、系统）、类别、动作、对象（类型、ID 与显示名）、摘要文案键与参数、结果（成功或失败及错误码）、请求 ID。不写凭据、正文、图像与完整模型输出。
- **用量**：运行结束时写入模型 ID、输入/输出令牌（服务返回时）、费用（服务返回时）、耗时；旧行保持原样。
