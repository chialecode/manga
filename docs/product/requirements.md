## 1. 产品定位与价值

MANGA 是一个本地优先、Agent 原生参与的二次元内容工作台。产品主线为：

> 围绕二次元内容，让阅读观看、随手记录、素材整理和辅助创作形成连续的工作流。

用户应当能够在阅读小说、漫画或观看动画时捕捉想法，将带有来源位置的记录复用为创作材料，并让 Agent 在明确的内容与项目范围内协助整理和产出。

核心价值由以下可验证行为体现：

1. 记录发生时保存内容位置，后续可以准确返回来源。
2. 一份材料可以被多个视图和项目引用，保持来源关系。
3. Agent 通过结构化状态理解任务，并调用与界面相同的业务能力。
4. 用户可以关闭 AI 或停用某个功能，数据保持可恢复、可导出。
5. 功能模块能够在另一个宿主中独立运行，为拆分应用提供基础。
6. 下载能力可以后装，外部动漫数据库可以替换或按字段组合，本地收藏、文件和引用不被外部服务绑定。

组合机制见[可组合与 AI-Native 架构](../design/composable-ai-native-architecture.md)。元数据首批接入 Bangumi，下载首批采用 BitTorrent；具体引擎在对应阶段选择。

首版平台与账户基线已于 2026-09-19 确认：本地单用户、基础功能无需登录、Windows 11 x64 首发；其他桌面系统后续独立验收。安装形式等未决事项按台账处理；基础技术按 [ADR-0007](../decisions/0007-technology-stack.md)实施。

## 2. 用户、模式与工作范围

### 2.1 用户类型

| 用户 | 主要目标 | 高频场景 |
| --- | --- | --- |
| 爱好者 | 管理与消费本地二次元内容，保存感想 | 续读续看、查找作品、划线、语音记录、询问当前内容 |
| 内容创作者 | 将资料和想法组织为作品 | 素材收集、人物与设定整理、提纲、文案、片段拼接 |
| 同时具有两种身份的用户 | 将消费过程积累的材料自然转为创作输入 | 看完一集后，把感想和片段加入某篇评论或视频脚本 |

### 2.2 双模式

- **爱好者模式**默认展示资源库、最近阅读观看、进度和随手记录。
- **创作者模式**默认展示项目、笔记、白板、思维导图、文案与粗剪。
- 模式是工作区预设，使用相同的资源、笔记与引用；可见导航、布局和 Agent 默认任务提示可以不同。
- 模式切换保留已打开内容、播放状态、草稿和 Agent 任务；必要的能力依赖保持运行。
- 功能开关与模式切换分别管理。隐藏一个页面不会自动停用其后台能力。

### 2.3 个人资源库与项目

个人资源库管理作品、版本、本地资源、进度与个人记录。项目管理一项创作任务的目标、材料集合、项目对象、术语与 Agent 会话。

一个资源可以被多个项目引用。笔记等创作对象有一个明确的所属范围，其他项目通过引用复用。Agent 默认使用当前任务允许的项目材料；跨项目材料需要被显式加入任务范围。

## 3. 核心用户旅程

### 3.1 阅读并记录

导入小说 → 调整阅读样式 → 选中一段文字 → 输入或说出想法 → 生成带引用的笔记 → 重启应用后继续阅读 → 从笔记返回原文。

成功条件：字体、窗口和文件位置变化后，引用仍可恢复或给出明确的修复入口。

### 3.2 观看时口述感想

打开动画 → 播放到某个场景 → 主动开始录音 → 继续观看或暂停 → 转写与整理 → 查看关联时间 → 点击笔记返回对应片段。

成功条件：笔记位置由录音当时的内容状态决定；异步识别延迟、倍速和跳转得到正确处理。

### 3.3 把记录变成创作材料

选择个人记录 → 加入项目 → 拖入白板 → 与人物设定关联 → 放入思维导图提纲 → 生成文案草稿 → 查看依据并修改。

成功条件：同一材料保持可识别的身份，引用可追溯，编辑与复制语义清晰。

### 3.4 Agent 跨页面协作

用户选中材料 → 查看 Agent 将使用的上下文 → 提出任务 → Agent 检索授权材料并调用工具 → 展示草稿或变更结果 → 用户继续编辑或撤销。

成功条件：任务固定目标与版本；切换页面不会将结果误写到新页面。

### 3.5 以引用片段组成粗剪

收藏动画时间范围 → 加入粗剪项目 → 排序与预览 → 检查实际可导出的切点与兼容性 → 导出新文件。

成功条件：保留来源与请求区间，导出结果明确标注实际区间，原始素材保持完整。

## 4. 范围与交付原则

M1 按 Agent 优先交付：M1a 建立 Agent 主页面、OpenAI 格式文本/转录接口、连接设置、首次配置和资源总览；M1b 接入小说、笔记与录音完整流程。M2 扩展漫画与动画；M3 完成创作组织；M4 完成限定范围的粗剪与插件分发。M0 负责在正式实现前验证关键约束。

基础模型、引用、命令、模块生命周期和导出协议从 M1 建立。后续功能接入既有协议，并根据验证结果调整模型。

以下暂不进入 M1—M4：实时多人协作、云账户与同步服务、复杂视频特效与任意格式转码、未获授权的内容下载、DRM 解锁、全系统自动听写、游戏平台或游戏运行引擎。Game 的具体产品需求在 vNext 单独定义。

## 5. 功能需求

表格中的里程碑表示首次必须满足的阶段；标注扩展时，其后续行为分别验收。

### 5.1 产品基础

| 编号 | 必须具备的行为 | 阶段 |
| --- | --- | --- |
| BASE-01 | 所有业务功能都向 Agent 开放同一套受授权约束的查询/命令；界面共享应用服务，每个模块声明上下文与事件；新增功能同步验收两种入口 | M1，后续持续 |
| BASE-02 | 两种模式共享数据，保留内容状态和草稿；基础消费与编辑在无模型配置时可用 | M1，M3 扩展创作导航 |
| BASE-03 | 模块有清晰依赖和宿主接口；至少将小说模块装入最小独立宿主完成验证 | M1 |

### 5.2 资源库与进度

| 编号 | 必须具备的行为 | 阶段 |
| --- | --- | --- |
| LIB-01 | 导入本地文件或目录；默认建立索引，可选择复制管理；支持进度、取消、错误报告和重复资源识别 | M1；M2 扩展媒介 |
| LIB-02 | 按作品、版本、卷章或集组织资源；支持封面、别名、语言、标签、收藏和手动修正；保留元数据来源 | M1；M2 扩展媒体信息 |
| LIB-04 | 提供专门的资源总览页，汇总资源、工程、笔记、剪辑、录音及存储位置/占用/可用状态；按类别筛选并进入管理或修复 | M1a 基础；随模块扩展 |
| LIB-03 | 记录最后位置、已消费区间和完成状态；支持续读续看、重置、手动标记与历史查看；不同版本和改编作品的进度分别保存 | M1；M2 扩展媒介 |

导入不以文件路径作为资源身份。移除资源库条目与删除磁盘文件是两个明确操作；默认移除只改变资源库关系。已被引用的资源移除后，保留引用记录并提供重新定位入口。

元数据可以逐步补充。联网补全采用可选连接器，展示来源，允许用户保留自己的修改。

### 5.3 阅读与播放

| 编号 | 必须具备的行为 | 阶段 |
| --- | --- | --- |
| READ-01 | 阅读 TXT、EPUB、MOBI、PDF；提供目录、滚动或翻页、字体字号、行距、主题、选区、查找、书签和进度恢复 | M1 |
| READ-02 | 阅读 PNG/JPEG 图片目录与 CBZ，以及 EPUB、PDF、MOBI 漫画；提供自然排序、左右阅读方向、单页/双页、长条滚动、缩放、页/区域选择和进度恢复 | M2 |
| READ-03 | 播放支持矩阵内的本地视频；提供暂停、定位、倍速、音量、全屏、字幕、可用音轨选择、片段标记和进度恢复 | M2 |

首版目标按对应阅读/播放功能的交付阶段执行：

| 类型 | 必须覆盖的目标 | 验证边界 |
| --- | --- | --- |
| 文本（M1b） | TXT、EPUB、MOBI、PDF | TXT 编码切换；重排文本与固定页分别建立可恢复定位；PDF 扫描页无文本层时说明选区/搜索需要 OCR |
| 漫画（M2） | PNG/JPEG 目录与 CBZ，EPUB、PDF、MOBI | 容器条目顺序、固定版式/图像页、区域引用、长图预算与损坏页 |
| 动画（M2） | MP4、MKV；H.264、HEVC（即 H.265）；AAC；ASS 字幕；多音轨切换界面；变帧率音画同步 | 用容器×编码×字幕×音轨矩阵验证定位、倍速、同步；ASS 样式、字体和内封/外置轨道逐样本记录 |

这些是用户确认的目标，当前原型尚未全部实现。DRM 解锁不在范围内；加密、损坏和实际不支持的子特性需明确说明。既有 SRT/WebVTT 和其他图片样本证据保留，不能以旧原型的 HEVC 拒绝记录撤销本次目标，也不能仅凭扩展名宣布全部变体可用。

### 5.4 笔记与引用

| 编号 | 必须具备的行为 | 阶段 |
| --- | --- | --- |
| NOTE-01 | 创建独立笔记或带来源的记录；支持文本输入、选区摘录和语音产出的整理稿；提供草稿自动保存 | M1 |
| NOTE-02 | 引用小说范围、漫画页/区域、视频时间范围以及创作对象的块/节点；显示来源卡片，支持跳转、返回与失效修复 | M1；M2/M3 扩展定位类型 |
| NOTE-03 | 提供基础结构化编辑、列表、标题、引用、代码或纯文本块、撤销重做和修订记录；AI 修改可以比较和撤销 | M1 基础；M3 扩展 |
| NOTE-04 | 支持标签、筛选、搜索、反向引用和项目归属；原文摘录、用户评论和 AI 派生内容有可辨识来源 | M1 基础；M3 反向引用视图 |

引用至少保存目标 ID、目标版本或实时引用策略、定位器和适量的恢复信息。记录的内容不会因为来源临时不可用而消失。AI 整理稿与转写原文分别保存。

### 5.5 语音记录

| 编号 | 必须具备的行为 | 阶段 |
| --- | --- | --- |
| VOICE-01 | 用户主动选择麦克风；同时支持按住录音和切换开始/停止，显示明确录音文字、提示灯和真实采集状态；用户口述与媒体转写使用独立输入链路 | M1 |
| VOICE-02 | 在录音片段开始时绑定活动资源和位置；记录翻页、暂停、倍速、跳转与资源切换；一段录音可关联多个内容区间，分段映射见 VOICE-08 | M1；M2 验证动态播放映射 |
| VOICE-03 | 录音经过 ASR 得到原文，再由可选模型整理为笔记；支持修订、角色术语纠正和手动调整来源 | M1 |
| VOICE-05 | 后台录音显示悬浮框，含录音文字、提示灯、持续时间和停止入口；用户可设置默认位置与大小，屏幕变化后保持可达 | M1b |
| VOICE-04 | ASR 或整理失败时保留已确认保存的原文和位置；已保存录音与临时处理音频按保留策略区分，支持取消、可恢复重试、仅保留原文及明确清理状态 | M1 |
| VOICE-06 | 支持一次持续几十分钟的录音；向远端 ASR 上传前在本地筛除无人声区间，仅上传待识别的人声片段并按接口限制分块；全程无人声时不上传，显示筛选/上传/转录进度与可恢复失败状态 | M1b；M2 扩展媒介 |
| VOICE-07 | 设置可选择保留或不保留音频；以消息气泡或分段进度条快速回顾语音/文本和跳转来源；不保留音频时仍保存转录文本、区间及来源，真实显示音频不可回放 | M1b；M2 扩展媒介 |
| VOICE-08 | 每个转录语音段保存原始采集区间及当时的内容位置：小说语义位置、漫画页面、动画播放时间；筛除静音、分块、异步返回与音频清理均不能使锚点漂移，跨翻页/资源/播放跳转保存多个锚点或拆段 | M1b 小说；M2 漫画/动画 |

首版同时支持应用内按住录音与切换录音；后台悬浮框持续显示真实录音状态。系统混音不接入用户口述链路；麦克风拾取外放声音仍需要回声消除、降低播放音量或耳机配合。必须展示真实采集状态，并用外放样本评估误识别，不能承诺所有设备完全排除对白。

用户录音属于原始数据，不作为可随意清理的缓存。设置中的保留选择在采集时明确，初始默认值和失败/取消的临时音频清理时机见 Q-05；变更设置不自动删除已有录音。不保留模式的临时音频在成功持久化文本与映射后清理，失败/取消显示恢复与清理状态；已有授权范围内的转写不重复打断询问。

VOICE-06—08 是 A-30 确认的后续需求：M1b 实现采集、筛选、回顾及小说定位，M2 补漫画与动态播放映射，不扩大 M1a 的文件转录返工范围。人声筛选不等于已解决回声、背景对白或说话人区分；精度与长录音边界须独立实测。

### 5.6 上下文感知

| 编号 | 必须具备的行为 | 阶段 |
| --- | --- | --- |
| CTX-01 | 每个页面声明可查询的业务状态、活动资源、位置、选区和相关对象；临时界面状态与持久数据分开提供 | M1，新增页面持续接入 |
| CTX-02 | 发起任务时保存上下文快照、目标资源和版本；支持跟随当前焦点或固定材料；过期结果不得误写其他对象 | M1 |
| CTX-03 | 上下文按用户授权、项目范围、内容进度和任务预算选择；可查看与移除来源；资料中的文本保持数据身份 | M1 |
| CTX-04 | 小说提供结构化正文；漫画按需提供页/区域与 OCR；动画按需提供字幕和帧；结果标明来源范围和提取方式 | M1 文本；M2 图像/视频 |

“所有状态可感知”指授权业务状态具有结构化查询方式。API 密钥、系统凭据和无关私人数据不会作为内容提供给模型。事件更新用于维护状态，连续滚动或播放不会触发逐事件模型调用。

防剧透模式限制检索和上下文构造到用户设置的已读/已看范围，允许用户显式扩大范围。模型已有知识仍可能带来泄露风险，因此界面表述为降低剧透风险的约束，不承诺绝对无剧透。

### 5.7 Agent 操作

| 编号 | 必须具备的行为 | 阶段 |
| --- | --- | --- |
| AGENT-01 | Agent 调用有类型与运行时校验的工具，通过应用服务查询或修改；工具执行受当前模块状态与授权约束 | M1 |
| AGENT-02 | 任务具有排队、运行、等待输入、成功、失败、取消等可见状态；支持停止；页面切换不改变任务目标 | M1 |
| AGENT-03 | 展示使用的材料和主要操作；可撤销的修改支持撤销；大批量或不可逆操作先形成具体预览，再按授权策略执行 | M1 |
| AGENT-04 | 区分读取、生成草稿、修改对象、文件写入和外部访问；授权可按任务或范围复用，避免每一步重复确认 | M1 |
| AGENT-06 | 提供以 Agent 为主要角色的独立交流页面，支持会话、材料、文本/转录输入、任务与工具结果核对；其他页面保留副驾驶入口，共享任务状态 | M1a |
| AGENT-05 | 按当前装配、授权和任务范围发现能力；技能不能授予权限或自动启用插件；业务结果、工具版本与证据可核对；Agent 运行时可替换，首版 BYOK、自研与 PI 实现可在设置切换 | M1 基础，M3 技能扩展 |

典型任务包括：解释当前选区、整理刚才的感想、查找授权材料、把记录加入项目、基于引用生成提纲、整理白板关系和创建片段清单。模型不可用时，已经存在的资料、工具界面和人工编辑继续可用。

### 5.8 创作工作区

| 编号 | 必须具备的行为 | 阶段 |
| --- | --- | --- |
| CRE-01 | 创建项目、维护目标与材料集合、术语表、人物/设定笔记；关联个人资源与记录；拥有明确的会话范围 | M3 |
| CRE-02 | 白板支持卡片、文字、引用、连线、分组、移动缩放、框选、排列、撤销与持久化；卡片可来源于两种模式 | M3 |
| CRE-03 | 思维导图支持根节点、子节点、兄弟节点、折叠展开、排序、拖动调整父子关系、主题、导出和引用 | M3 |
| CRE-04 | 笔记、白板和思维导图支持对象及局部内容的互嵌；区分实时引用和快照；处理循环、失效、停用与权限范围 | M3 |
| CRE-05 | 文案支持提纲、续写、润色、翻译、按术语表改写和引用材料生成；提供差异预览与版本恢复 | M3 |
| CRE-06 | 搜寻本地材料及可选外部资料；结果保存来源 URL、获取时间和选取片段；用户可加入项目并用于有依据的创作 | M3 |

思维导图的父子关系构成树，白板连线和跨对象引用构成一般关系图，分别维护。编辑嵌入内容时明确正在编辑源对象；“复制一份”创建新对象，并保留来源信息。

联网研究只发送任务需要的查询与已授权材料。检索结果和原文是可引用的数据，其文本不能自行提升为系统指令或授权。

| CLIP-01 | 以源资源、请求起止时间和排列顺序组成单序列粗剪；支持添加、移除、调整、预览、撤销和来源跳转 | M4 |
| CLIP-02 | 导出前检查流兼容性和可用切点；显示请求区间与实际导出区间；支持取消、错误恢复和导出新文件；保留原始素材 | M4 |

### 6.2 初始性能目标

以下为设计目标。M0 必须记录实际机器、资源样本与测量方法，并对门槛定稿；远程模型延迟不计入本地响应指标。

首轮参考环境：经确认的 Windows 11 x64 环境、单主窗口。保留下表响应时间目标，公开报告记录平台、构建版本和测量方法，设备明细留在本地脱敏前记录；10,000 条资源元数据、50,000 个可检索文本块；测试用媒体来自支持矩阵。结果仅适用于被测机器，不外推最低配置。

| 项目 | 初始目标与口径 |
| --- | --- |
| 本地界面反馈 | 常用按钮、输入与任务启动反馈 p95 ≤ 100 ms，不含任务本身完成时间 |
| 已加载页面的轻量上下文查询 | p95 ≤ 150 ms；返回位置与选区元数据，全文/OCR 另行异步请求 |
| 本地全文搜索 | 索引就绪时前 20 条结果 p95 ≤ 500 ms |
| 冷启动至可操作资源库 | 在基准库规模下 ≤ 5 s |
| 已索引小说首屏 | TXT ≤ 10 MiB、EPUB ≤ 30 MiB 样本上 p95 ≤ 2 s；重解析单独报告 |
| 录音状态反馈 | 开始或停止请求后 ≤ 300 ms 内展示真实状态或设备错误 |
| 自动保存 | 编辑草稿目标 ≤ 1 s；连续阅读/播放进度目标 ≤ 2 s，暂停/跳转/关闭时立即提交 |

应用必须区分“正在保存”和“已保存”。异常退出前尚未得到持久化确认的瞬时状态不承诺零丢失，但应恢复最后已提交状态。

### 6.3 内容与数据正确性

- 来源定位使用资源 ID 与版本，位置恢复包含校验和明确的失败状态。
- AI 生成内容记录输入来源、配置模型和生成时间，不能将生成摘要标记为原文。
- 已消费范围由实际消费事件或用户显式标记形成，跳转经过的内容不会自动全部计入已读。
- 嵌入模型或分段规则变化后旧索引不可混用，重建期间全文搜索继续可用。
- 用户录音、笔记和项目属于原始业务数据；封面缩略图、OCR 索引等可再生内容分别管理。

## 7. 典型异常及预期产品行为

| 异常 | 预期行为 |
| --- | --- |
| 资源移动、改名或磁盘离线 | 保留条目与引用，提示定位资源；根据内容校验恢复，不能静默链接到同名文件 |
| 原文或视频被替换 | 创建或识别新版本，校验锚点；无法可靠映射时由用户修复 |
| 没有 API key、模型能力不匹配 | 展示所缺能力；本地阅读、人工记录与已有内容可用 |
| 转写成功、整理失败 | 保留转写原文与位置，允许稍后整理 |
| Agent 生成期间用户编辑目标 | 按版本冲突处理，保留建议稿，允许比较与合并 |
| 正在使用的模块被停用 | 提示受影响功能，按停用流程处理任务并释放资源，数据保留 |
| 嵌入目标存在循环或模块不可用 | 展示可跳转的引用卡片或预览，不无限展开 |
| 无转码导出不兼容 | 报告具体不兼容项，保留编辑项目，不悄悄切换为高成本转码 |

## 8. 产品效果与验收方式

产品效果通过本地场景验证与用户测试观察，不默认上报内容或行为遥测。

- 能否从阅读/观看自然创建记录，且不丢失位置。
- 能否从记录返回原文、画面或片段。
- 能否将同一材料复用于多个创作视图。
- Agent 结果是否有依据，操作是否发生在正确目标上。
- 停用模块、切换模型、断网和资源迁移后是否仍能继续工作。

每项需求的测试入口、阶段门槛与用例映射见[交付阶段与验收计划](../delivery/roadmap-and-acceptance.md)。完成一个页面或一个按钮不等于完成对应需求，必须通过其完整流程和关键异常验收。
