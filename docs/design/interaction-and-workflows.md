## 1. 交互原则

界面与编辑基础采用 [ADR-0007](../decisions/0007-technology-stack.md) 的 React、Radix、Tiptap/ProseMirror 与对应源编辑场景的 CodeMirror 6。选型不改变下述工作流、块/引用身份、业务历史与后台生命周期；旧 textarea 原型的人工证据不继承到新界面。首版 UI 为中文并保留多语言扩展；语义 Token 和主题数量仍按待决范围处理。

1. 阅读/创作页以内容为主，Agent 为可收起的副驾驶；独立 Agent 页以交流、任务和结果为主面板。
2. 阅读、记录和创作的切换保留正在进行的工作。
3. 记录先明确保存到哪里、引用哪里，再提供智能整理。
4. Agent 展示使用材料和结果去向，用户可以控制任务与撤销修改。
5. 失败保留已完成的工作，并给出可以继续操作的恢复入口。

## 2. 应用壳与三栏布局

### 2.1 默认结构

```text
┌──────────────────────────────────────────────────────────────────────────┐
│ 侧栏图标       当前内容标题             命令入口       任务与录音状态    │
├───────────────┬─────────────────────────────────┬────────────────────────┤
│ 模式菜单      │ 当前资源 / 工程                      │ Agent                  │
│ 功能导航      ├─────────────────────────────────┤ 上下文与来源           │
│ 笔记          │                                 │                        │
│ 已打开会话    │            主面板               │ 会话 / 当前任务        │
│ 资源 / 工程   │                                 │                        │
│ 粗剪          │ 阅读、观看、编辑或组织材料       │ 结果、引用与操作       │
│               │                                 │                        │
│ 设置 / 模块   │                                 │ 输入与任务控制         │
└───────────────┴─────────────────────────────────┴────────────────────────┘
```

上图表示空间足够时的区域关系，不要求每个页面常驻三栏。页面入口按模式和启用模块动态显示。尚未交付的功能不显示成可以使用的空页面。独立 Agent 页以会话为主面板，阅读页以正文为主面板，设置与资源页也使用剩余宽度，不预留没有内容的副驾驶栏。

### 2.2 尺寸与响应

| 区域 | 初始建议 | 行为 |
| --- | --- | --- |
| 左栏 | 默认 224 px，可调约 200—280 px | 可折叠为约 56 px 图标栏或完全隐藏 |
| 主面板 | 优先分配剩余宽度，640 px 为阅读/编辑初始目标，非窄窗硬下限 | 宽屏可分屏，正文行宽另设上限 |
| 右栏 | 默认 360 px，可调约 320—480 px | 可隐藏，小窗口采用抽屉 |
| 顶部壳 | 侧栏图标、标题与必要任务入口融入同一紧凑区域 | 专注状态减少装饰；窗口控制、退出入口和快捷键仍可访问 |

初始设计曾建议 960 × 640 px；A-32 明确要求手机比例窄长窗口，所以代码下限现为 360 × 360，默认 1280 × 840，360 × 780 CSS 视口是验证目标（宽 1280 × 840、窄 360 × 780、矮 1100 × 460 由打包窗口观察覆盖），这仍是可调整值。验证同时覆盖这些尺寸、宽屏与窄长窗口，记录 CSS 视口、外窗大小和缩放的区别；最终基线仍按 Q-08 实测，不通过提高最小窗口掩盖布局问题。断点按实际可用空间计算：先收起辅助区域，为主面板保留空间；不足以常驻时左右栏转为覆盖浮层。高度不足时压缩装饰和次级工具，内容与操作区分别有可达的滚动路径，不把输入、保存或停止入口挤出窗口。

专注状态仅保留主面板及必要的可唤回控制。左右栏、顶部壳、面板宽度与分屏分别保存为用户布局偏好；模式可有不同布局。

### 2.3 显示状态与业务状态

- 隐藏 Agent 不取消正在进行的任务；全局任务入口可查看和停止。
- 隐藏导航不卸载模块；切换标签不自动清空草稿。
- 播放和录音会话由业务服务持有。是否在切换内容时暂停由用户偏好决定，并显示实际状态。
- 模式切换调整导航和默认建议，已经打开的内容仍保留，包括从另一模式打开的页面。

### 2.4 隐藏侧栏与悬浮展开

UI-06 的“悬浮面板”包含可操作的侧栏内容，按钮提示只是辅助标签。标题最左端提供左侧栏图标，右辅助区域使用对应图标；图标具有可访问名称与提示。侧栏不可用时不显示空入口。宽窗常驻、用户主动隐藏、空间不足自动隐藏与临时浮层是不同状态。

- 正常宽窗侧栏占据布局空间，按钮用于收起/恢复常驻，不以浮层遮挡主面板。只有视口不足以常驻时，鼠标悬停按钮才临时展开；指针从按钮移入面板可连续操作，移出且面板内无焦点时收起。延迟和防抖由实现试验决定，不能产生来回闪烁。
- 点击、Enter 或 Space 可固定打开浮层；无悬停设备通过点击使用。键盘有明确关闭入口，Esc 关闭后恢复到触发按钮；悬停本身不抢走编辑焦点或提交输入法组合。
- 窄窗同一时刻优先展示一个辅助浮层，避免左右同时覆盖全部正文。浮层有可见边界、可滚动内容及关闭入口；关闭后原正文选区、阅读位置与草稿保留。
- 自动折叠属于当前视口的派生状态，不覆盖用户保存的面板宽度和显隐偏好；恢复宽窗时恢复可容纳的用户布局。临时悬停状态不在重启后强行恢复。
- 隐藏侧栏不卸载模块、不复制会话；正在运行的任务及后续录音仍有全局状态和停止入口。

### 2.5 工作模式菜单与沉浸式标题

UI-07 在左侧栏顶部以观测者/造物主双选项显示当前模式，旁边保留带当前模式可访问名称的展开按钮，不放在标题栏。双选项提供直接点击/键盘 Tab 入口；菜单方向键选择、Enter 确认、Esc 退出并恢复焦点。工作模式与 Agent 主页面/副驾驶的展示位置分别管理；也不把模式菜单用作 Profile、模型或 AI runtime 切换。显示名更新后持久值仍为 `enthusiast` / `creator`，不重建布局、会话或草稿。

两种模式访问同一资源和笔记，造物主模式只呈现已交付入口。切换过程中若保存尚未完成，保留草稿和真实保存状态，不重建业务对象或重发运行任务。

沉浸式标题以减少独立标题带和重复页面标题为目标，统一顶部表面与主工作区。Electron 实现需要验证拖动区与控件的非拖动区、最小化/最大化/还原/关闭、系统快捷键、贴靠及长标题省略；不要求透明材质或额外动效。系统按钮保留命中区域，不被菜单或浮层遮住。

UI-08 的主面板占用剩余空间；阅读正文行宽与壳宽分开设置，宽屏可用于记录、资料或用户打开的分屏。减少固定外边距、空辅助栏与重复说明；不能通过缩小字号、移除可访问标签或自动铺开尚未启用的功能来提高利用率。

### 2.6 打开的会话与资源占用

左栏上部提供功能入口，下部列出当前打开的会话；观测者模式对应资源，造物主模式对应工程。关闭标签只关闭视图；保存的笔记、进度、引用和已发出的任务不随标签销毁。切换后右栏显示该会话的 Agent 和材料，晚到结果仍归原会话。小说、漫画、动画的资源各有会话；工程内容接入后，造物主模式的会话对应工程。

非活动且未播放的媒体保留轻量身份、进度、用户偏好和恢复描述，暂停解码、渲染与高频轮询，并按预算释放帧/图片缓存。后台播放是显式行为，不能因切换页面暗中创建更多播放器。测试同时打开多个合成资源，记录前后台 CPU、内存、解码活动和恢复时延；预算见 Q-11，未测不得宣称低占用。

## 3. 视觉与可访问性

### 3.1 初始视觉参数

2026-09-24 起，这一版应用壳精确颜色、间距、圆角、面板阴影和响应式组件样式由 [styles.css](../../apps/desktop/src/renderer/styles.css)作为代码正本，不在文档另维持一张颜色表。语义 Token 包括背景、表面、次级表面、分隔线、文字、次级文字、强调色/轻背景、品牌标志、危险与焦点。浅灰壳、白色内容面板、淡粉选中态与深粉操作文字形成层级；浅分隔线不承担唯一焦点提示。

粉色用于主要动作、选中、焦点和少量状态提示；正文与长时间阅读以深色文字和稳定背景为主。阅读器可以单独调整背景、字体和行宽，不改变应用壳的品牌主题。

语义 Token 位于 `apps/desktop/src/renderer/styles.css`。2026-09-20 已授权先形成一版可替换主题；字体可选系统栈（含 Segoe UI）、HarmonyOS Sans SC，代码字体按需提供 JetBrains Mono，并保留本机字体回退。采用字体资产前核验许可、中文覆盖与离线打包。最终自有主题数量、数值与窗口基线仍按 Q-08 评审；不把参考候选视为全部已选或验收通过。

正文对比度目标至少 4.5:1，关键控件边界和焦点需清楚可见；浅分隔线只能用于装饰，不承担唯一的控件边界。状态同时提供文字或图标，不只依赖颜色。

### 3.2 键盘与输入

- 命令面板、资源导航、笔记编辑、引用跳转、录音和任务停止都提供键盘路径。
- 焦点移动顺序与视觉顺序一致，抽屉/弹窗有明确的进入、退出和焦点恢复。
- 中文输入法组合期间不提交段落、不触发快捷命令，也不破坏选区。
- 快捷键可配置，避免覆盖输入框、阅读翻页和系统快捷键。
- Esc 关闭临时浮层，不能无提示地丢弃已录音频或编辑草稿。
- 动画保持轻量，尊重减少动态效果偏好；大列表、画布和内容页面采用渐进加载。

### 3.3 首版界面切片

A-37 把现有小说阅读、笔记、对话与共享壳统一为白灰粉三栏界面。左栏显示品牌、双模式、带线性图标的已交付功能、打开会话与底部设置；资源占位封面使用本地矢量图标，不制造不存在的收藏。右栏标题、当前模式、上下文、材料、消息与输入区复用同一会话业务状态。输入靠底部，窄窗辅助区以可关闭浮层显示；授权句柄和工具 JSON 收入“任务详情”，不放在普通消息主层级。

代码位于 `apps/desktop/src/renderer/` 的 `shell.tsx`、`brand.tsx`、`App.tsx` 和 `styles.css`。Q-08 最终视觉批准、真实 IME 与系统 DPI 不因此通过。

**共享壳。** 左栏自上而下：品牌与标语；观测者/造物主双选项（沿用 A-32/A-37）；功能导航“总览、对话、小说、漫画、动漫”（“游戏”属 vNext，首版不显示，见 Q-10）；下部分组列表按媒介显示数量（如“小说 (8)”），可展开，列出最近打开或已打开的资源会话，每项带小封面、标题、作者或当前话/页（如“第 01 话 · 12/28”），当前会话高亮并带继续图标；分组旁有“管理”入口进入对应资源页；底部“设置”。分组标题文案待 Q-18。右栏为“MANGA Agent”：标题、快捷任务标签行（资源库为“书籍分析 / 剧情解析 / 角色分析 / 创作助手”，漫画阅读为“漫画分析 / 剧情解析 / 角色分析”，小说为“剧情解析 / 角色分析 / 世界观设定”），对话区，回答中引用资源时显示带封面的资源卡片及“查看详情 / 打开”按钮，回答下方可有建议追问标签，底部输入框。快捷任务把预设问题连同当前上下文作为一条可见的用户消息发送，不是隐藏指令。参考图中“为你推荐相似作品”的位置显示“相关作品”：已关联条目的 Bangumi 关联条目（标注续集、前传等关系，本库已有的标“已在书架”）和本库中标签相近的作品，每项标明来源，不调用模型；模型生成的推荐见 Q-21。录音按钮与状态（文字、提示灯、时长）在顶部壳的任务与录音状态区，三种阅读器工具栏也提供录音入口，交互见第 7 节。标题栏右上角最小化/最大化/关闭按钮颜色跟随应用主题。

**资源库页（参考图 1）。** 页面标题如“我的书籍”（单媒介页为“我的漫画”等）；右上为搜索框（书名、作者或标签）；没有“导入”按钮，资源来自资源库位置（见 3.6）。其下为书架状态标签“全部 / 在读 / 想读 / 已读 / 搁置”，右侧为网格/列表切换、排序（最近打开、最近添加、标题、进度）与筛选（格式、是否已关联资料、有无笔记）。“全部”页按媒介分区，每区标题为图标 + 名称 + “共 N 本/部”，右侧“查看全部”；区内横向一行卡片，可左右滚动。书籍与漫画卡片为竖版封面，动漫卡片为横版画面并叠加播放图标。卡片下方：标题、作者或制作方、当前进度文字（如“第 101 话 尼瑙”“第 12 卷”“更新至第 28 集”），以及状态标签（在读、搁置）或带百分比的进度条（“已读 78%”）；卡片右上“…”菜单含打开、详情与匹配资料、更换封面、设置状态、移出资源库。无封面时显示本地占位图形而非空白。空库、加载中、部分失败、离线与模块停用都有对应状态。

**作品详情。** 从卡片菜单或右键进入，可为抽屉或页面：封面（可更换、锁定）、投影后的标题/原名/作者/简介/标签/评分（每个字段标明来源，如 Bangumi 或文件内置资料，以及抓取时间）、卷/话/集列表（可带 Bangumi 集标题）与各自进度、相关笔记、录音回顾、相关作品、书架状态；“匹配 Bangumi”打开候选列表，人工确认后才关联。

**漫画阅读器（参考图 2）。** 顶部工具栏：返回、作品名 + 话标题 + 媒介标签、页码选择（“第 12/28 页”下拉）、上一页/下一页、书签、适配与全屏、更多。点击设置打开“阅读设置”面板：阅读方向（从左到右 / 从右到左）、显示模式（单页 / 双页 / 连续滚动）、自动翻页开关及间隔、翻页动画（淡入淡出 / 滑动 / 无，减少动态效果时为无）、高级设置（封面单独显示、缩放与铺满方式、预加载）。主区显示页面；底栏：作品小封面与标题、话标题、上一页/下一页与“12 / 28”、视图按钮（适配宽度、适配高度、原始大小、全屏）。键盘左右键遵循阅读方向，另有空格、PageUp/PageDown、Home/End 与缩放快捷键；框选区域后可记笔记，来源卡片返回同一页与区域。

**小说阅读器（参考图 3）。** 顶部：返回、书名 + 媒介标签、作者与当前章节；右侧“书签”和更多。工具栏：A- / A+ 字号、字体下拉（系统已安装字体与预设）、五个背景色块（白、书本黄、护眼绿、青绿、深色）、单页/双页切换、“按书籍比例”页面比例、宽度与全屏、“更多设置”（行距、边距、段距）。双页模式以对开页显示，页眉为书名 · 章节，页脚为页码；单页模式保留滚动阅读。阅读器背景只影响正文区域，不改变应用壳主题。现有选区、笔记、来源返回、查找与进度行为不变。

**动漫播放器。** 参考图未包含，沿用 A-33 与 READ-03：画面为主，控制条含播放暂停、进度条（含片段标记与录音区间）、可点击编辑的时间、倍速、音量、字幕与音轨选择、全屏；画面下方为作品信息、集列表（横版缩略图与集标题）和笔记操作。文件需要播放副本时（无硬件 HEVC 或不支持的音轨），画面区显示原因、“生成播放副本”按钮、进度与取消，而不是黑屏。默认快捷键按 Q-13 推荐值实现并可在后续调整。

### 3.5 人工反馈后的界面结构（2026-10-06）

**总原则：观测者模式的读写分离。** 阅读和观看时，主面板只做资源的只读操作：浏览、打开、翻页、播放、缩放、选择文字或画面区域。产生记录的操作（记笔记、录音、提问）都在右栏完成；在主面板上做的选择只作为引用标签带进右栏输入框。作品资料的编辑与外部匹配在作品主页进行，不属于阅读页。

**主页面保持简洁。** 每个页面只直接显示常用操作，其余收进“…”菜单或设置面板。判断标准：一次阅读或观看中会反复用到的才常驻（翻页、播放暂停、进度、页码、全屏）；设定一次就很少再改的放进“…”（漫画阅读方向、单双页、自动翻页、翻页动画、字幕样式、音轨、帧号输入、逐帧、播放副本等）。提示用短暂通知（右下角，数秒后消失；错误保留到关闭），不在主面板上方常驻横幅。

**左栏与导航。** 观测者导航为“总览、对话、小说、漫画、动漫”，底部为“设置”；原“笔记”入口并入设置的“记录”。“小说/漫画/动漫”始终打开对应书架，不随正在打开的资源变化。已打开的资源在左栏下部按媒介分组列出，每行显示小封面、标题和当前位置（如“第 01 话 · 12/28”“第 3 集 · 12:30”“第二章 · 34%”），点击回到该资源会话并恢复位置；不显示“资料 · 0”之类的内部计数。

**作品主页。** 点击书架上的作品卡片进入作品主页，不直接打开文件。布局参照 Bangumi 条目页：
- 头部：封面、标题与原名、作者或制作方、媒介与年份、话/集数、评分（标明来源站点与抓取时间）、标签。
- 主按钮：“阅读”或“观看”，有进度时为“继续阅读 · 第 3 话 12/28”，点击才打开文件。旁边是书架状态选择、“匹配 Bangumi”（已关联时显示“Bangumi #464376”及菜单：刷新资料、更换条目、取消关联、在浏览器打开）、“编辑资料”和“…”（更换封面、移动资源、移出资源库）。
- 页签：概览（简介与全部资料字段，每个字段标明来源）、卷/话/集（列表与各自进度、单独打开）、角色（角色、关系与声优）、制作人员、记录（该作品的笔记与录音）、相关作品。
- 编辑资料：所有字段都显示并可填写，包括为空的字段；保存为用户修改，可锁定，可恢复为来源值。
- 返回书架时保持原书架的筛选与滚动位置。

**匹配 Bangumi。** 只能在作品主页由用户点击发起。对话框有两种方式：关键词搜索（预填标题，按媒介过滤类型）；按 ID 或链接（接受 `464376`、`subject/464376` 与 bgm.tv、bangumi.tv、chii.in 的条目链接）。选中条目后先显示预览（封面、名称、类型、日期、话/集数），条目类型与作品媒介不一致时提示但允许继续。确认前列出将要改变的字段与封面，用户可逐项选择“保留本地”；不确认就不写入。刷新资料同样先显示差异。书架上不再有“为未匹配作品查找”的批量入口。

**阅读与观看页。**
- 漫画：顶部为返回（回到作品主页）、标题与话、页码选择、上一页/下一页、全屏和“…”；“…”打开阅读设置（阅读方向、单页/双页/长条、封面单独、适配方式、自动翻页、翻页动画、预加载）。底栏为话标题、页码与进度条、视图（适配宽度/适配高度/原始大小，缩放在其中；也可用 Ctrl+滚轮与快捷键）。缩放小于 100% 时页面缩小并居中，大于 100% 时可滚动，适配方式随窗口大小变化。

- 三种页面上都不再有“记笔记”“录音”按钮。
- 窄窗时阅读器顶部的作品标题裁切显示（末尾省略），不与页码、按钮重叠；完整标题在标题栏。

**右栏：聊天窗口。** 右栏是当前资源会话的对话记录，不再罗列状态：
- 消息流按时间排列：笔记气泡、语音气泡、向 Agent 的提问与回答。笔记气泡带来源标签（如“第 12 页 · 区域”“12:30—12:45”“第二章 · 选区 128 字”），点击跳回来源；可就地编辑、删除（需确认）或引用来提问。语音气泡显示录音状态（录音中、转写中、已完成）、转写文字与各段来源，保留音频时可回放。
- 输入框：上方是引用标签行（当前选区、画面区域、A-B 片段、附图，可逐个移除）；输入框内有“笔记 / 问 Agent”切换（资源会话默认“笔记”，记住上次选择；切换只在有归属的地方出现——打开的资源和作品主页，书架、资源库等没有资源或作品的页面上输入框只问 Agent，也不改动记住的选择，避免写出一条无处显示的笔记）、麦克风（单击开始/停止，按住说话，松开结束）、附件与“+”菜单（联网、放宽字幕范围、选择材料等仅对本次发送有效的选项）、发送。
- 快捷任务标签在输入框上方，来自设置中当前页面适用的快捷任务。
- 未配置模型时，在输入框上方显示“尚未配置模型”和“去设置”，“笔记”模式不受影响。
- 右栏收起（专注、窄窗）时，主面板右下角显示悬浮胶囊：麦克风与记笔记；点记笔记弹出小输入框，发送后与右栏发送等效。录音中胶囊显示状态与时长。有自己底栏的页面（漫画页、播放器，全屏除外）上胶囊停在右上角、标题栏之下，笔记框向下展开；标题栏下方的提示条（框选提示、警告、来源卡）与播放器的字幕提示让出胶囊所在的角，胶囊不压住任何控件。没有资源或作品可归属的页面上，胶囊只有麦克风。
- 作品主页的右栏同样是对话；在这里发出的笔记关联到作品，不带阅读位置。

**对话页。** 整个主面板就是对话，不显示右栏，参照 Codex、Claude 桌面版：对话列表在左栏下部，主面板居中显示消息流（限制行宽），输入框在底部；空对话显示快捷任务与可用能力。

**标题栏。** 左侧为侧栏开关与标题，右侧为：上下文调试按钮、录音中的状态（文字、提示灯、时长，点击停止，只在录音时出现）、扫描或任务进度（只在进行中出现，点击打开对应设置页）、右栏开关，以及跟随主题的窗口按钮。删除原来打开录音回顾的麦克风按钮。

**上下文调试面板。** 点标题栏按钮（或快捷键）在主面板下方展开，可调整高度，只读，用于调试：
- “当前”：下一次发送将使用的上下文，包括会话、资源与修订、位置与选区、字幕窗口、材料、模型路由、可用工具与授权范围。

- “复制 JSON”：凭据始终隐藏，图像字节只显示尺寸与哈希。

**设置界面。** 进入设置后，左栏换成设置导航，主面板换成设置内容，不显示右栏；左栏顶部“返回”回到进入前的页面。内容区居中，每行左侧为名称与说明、右侧为控件。导航分组：
- 基础设置：常规（数据位置、启动、语言）、外观、阅读与播放（三种阅读器的默认值，含“截图带字幕”）、录音（设备、保留策略、降音或暂停、悬浮框）、资源库（见下）、资料来源（Bangumi 开关与 access token）、存储与备份（资源总览、位置迁移、备份与导出、缓存）、模块、键盘快捷键。

### 3.6 试用反馈后的窗口、资源库与阅读器（2026-10-07）

2026-10-07 用户试用后提出 21 条反馈，决定见 A-67—A-73，验收见 AT-77—AT-85。本节是返工后界面的文字正本；与 2.x、3.4、3.5 冲突时以本节为准。

**标题栏与三栏。**
- 标题栏不单独占一行，不显示渠道文字，按三栏分段并与下方的栏对齐：左栏段从左到右是菜单（设置、扫描资源库、调试面板、关于、退出）、隐藏/显示侧栏、后退、前进、娱乐/工作模式两个图标按钮；主面板段是当前页面或已打开资源的标题（阅读器顶栏里的标题移到这里，作品页显示作品名，已打开的小说在作品有多个文件时显示“作品名 文件名”），右侧是调试按钮与录音、扫描进度；右栏段是右栏标题与开关；窗口按钮在最右。左栏隐藏时，标题紧跟在左栏段的按钮后面，窄窗只剩按钮时标题收起。

**左栏。** 自上而下：功能导航；一条分隔线；已打开的资源与会话，没有标题，按小说、漫画、动漫、项目分组，组标题可以点击折叠，折叠时显示数量，折叠状态记住；底部固定的“设置”，高度与导航行一致，只有中间的列表滚动。每个已打开的资源悬停时右侧出现关闭按钮，右键菜单有“关闭”：它只是把资源从左栏移走，资源会话和它的对话都保留；再次打开（从作品页、书架或“继续”）回到同一个会话和上次的位置，会话行上的位置文字（页码、时间、百分比）保持。

**资源库。**
- 书架和总览没有“导入”：入口是设置里的“资源库”页（添加资源库位置、扫描、移除）和书架空状态里的“添加资源库位置”链接。

- 不在任何资源库位置下的旧资源在卡片和作品页上标“库外”，并提示“把它们所在的文件夹加为资源库位置”。下载完成的文件落在已登记为资源库位置的下载目录里。

**阅读器与播放器。** 三种阅读器都没有顶栏：作品名在标题栏，返回用标题栏的后退，没有“下一集/下一话/下一章”按钮（末页点右侧也不再跳转；换集、换话用选集列表、目录或作品页，“自动播放下一集”的设置保留，默认关闭）。其余控件都在底栏：
- 漫画：全屏、区域工具、“…”设置面板、上一页/下一页与页码；页码点击后变为输入框，Enter 跳转，Esc 放弃。鼠标滚轮：单页与双页模式下滚一次翻一页；页面放大到可以滚动时先滚动页面，滚到边缘再翻页；按住 Ctrl 滚动以指针为中心缩放（25%—400%）；条漫模式滚轮正常滚动，Ctrl 加滚轮缩放（Q-24）。
- 动漫：播放暂停、进度条、点击可编辑的时间、倍速、音量、字幕与音轨、全屏、“…”；匹配 Bangumi 的入口在“…”与作品页。方向键：短按 ←/→ 按设置的步长跳转（默认 5 秒）；按住 → 超过 300 ms 按设置的临时倍速播放，松开恢复；按住 ← 连续快退，约每秒退 4 秒，松开停止。鼠标右键打开菜单，不再有长按倍速。快捷键帮助随之更新。
- 小说：目录、查找、书签、加书签、全屏与阅读设置在底栏；章节名在底栏。
- 控件不被右上或右下的悬浮胶囊、字幕提示遮挡；宽、窄、矮三种窗口里都核对过。

**字幕与播放诊断。**
- ASS 字幕里样式用的字体既没内嵌、本机也没装时，用含中日文字形的默认字体绘制：随包的开源字体（Noto Sans SC，装在应用资源里，随渲染器一起加载，所以第一帧就有；覆盖简体中文与日文，不含韩文）。字幕渲染器只在视频显示新的一帧时绘制，所以轨道在暂停的画面上选定后，会把正在显示的那一帧画一次，不必等下一帧。
- 播放器不能只显示一片黑：时间在走而已解码帧数不增加，或打开后 2 秒内没有第一帧，画面区显示“没有画面”的状态与“改用播放副本”按钮；能播放时一切照旧。
- 上下文调试面板的“当前”页新增一行视频：播放方式（原文件或播放副本）、`readyState`、`networkState`、已解码与丢弃的帧数、画面尺寸与健康状态，字幕渲染器及其状态、默认字体来源与缺失的字体。出现黑屏时请把这一行记下来（用户待办 H-30）。

**Agent。** 工作模式的项目会话里，Agent 可以读取本项目的对象，并做可撤销的写入：白板与导图的编辑标注为“Agent：…”，进入操作日志，可以在界面里撤销；文稿只能写成建议，显示“由 Agent 写成，采纳前不会改动文稿”，采纳由用户做。删除、导出、粗剪、语义检索、网页抓取、插件与下载不在 Agent 的工具清单里；娱乐模式的全局对话与资源会话没有项目命令（A-73）。

### 3.7 第二轮试用反馈后的窗口、模式与播放器（2026-10-09）

2026-10-09 用户第二轮试用提出 20 条反馈，决定见 A-75—A-84，验收见 AT-86—AT-98。本节是返工后界面的文字正本；与 3.6 冲突时以本节为准。

**栏顶与窗框色（AT-86）。**
- 没有单独的标题栏行。三栏各自有 36 px 高的栏顶，属于该栏；栏间 1 px 的分隔线从窗口顶部一直画到底，没有横贯的下边框。栏顶空白处可以拖动窗口，按钮不能。
- 左栏顶部是菜单（设置、扫描资源库、调试面板、关于、退出）、隐藏/显示侧栏、后退、前进与模式切换；主面板顶部是当前页面或已打开资源的标题与页面操作；右栏顶部是右栏标题与开关。左栏隐藏时，主面板顶部依次是菜单、显示侧栏、后退、前进、标题，模式切换收进菜单。
- 栏顶与阅读器底栏用同一个窗框色（`--color-frame`，沉浸时用半透明的 `--color-frame-glass`）。主题或沉浸状态变化时，窗口自己的按钮（最小化、最大化、关闭）的底色与符号色同步更新，不留下一块系统色。

**两种模式是两个工作区（AT-87）。**
- 导航、当前页面、后退前进历史、已打开的资源、右栏上下文与宽度都按模式分开保存；切换模式时恢复该模式上次的页面，没有用过的模式从总览开始。进度、书签、笔记属于资源本身，两种模式共用，设置是共用页面。
- 娱乐模式的导航是总览、全局对话、小说、漫画、动漫、下载；工作模式的导航是项目总览、项目与设置，项目里有材料、白板、导图、文稿、粗剪等工作区。项目模块停用时，工作模式没有自己的页面，与娱乐模式的页面相同。
- 工作模式的项目总览列出最近的项目（材料、白板、导图、文稿、粗剪的数量与最后编辑时间）、最近编辑的对象、待采纳的文稿建议，以及“新建项目”。从项目材料打开资源时，在工作模式里打开阅读器，右栏是该项目的会话。

**阅读器留在后台（AT-88）。** 进入设置、切到非阅读页、切换模式时，当前阅读器与右栏用 React 的 `<Activity>` 留在后台：同一个元素、同一个位置、同样的暂停状态，右栏里没发出的输入和对话的滚动位置都在，返回后不重新加载；媒体在进入后台时暂停，返回后保持暂停。打开另一个资源时仍释放上一个。以前“重新挂载后没回到上次位置”的根因是阅读器从“打开这个资源时的位置”起步，而不是从播放器最近一次报告的位置起步，现在两者都已改正。

**窗口全屏（AT-89）。** 三种阅读器的底栏都有“窗口全屏”按钮和快捷键（默认 W），与屏幕全屏是两个按钮。阅读器占满应用窗口，栏顶和底栏在内容上半透明悬浮，指针移到上沿时栏顶出现，窗口按钮随栏顶出现（A-91，见 3.8）。全屏时画面的尺寸不随底栏的显示与隐藏而变化；底栏是半透明的玻璃层，字幕层随底栏抬高。

**播放器的控制（AT-89、AT-90）。**
- 底栏左边是播放、时间与帧号；右边依次是字幕（主字幕与次字幕在同一个菜单里，见 3.8）、音轨、选集、倍速的菜单，弹幕、音量、截图、窗口全屏、屏幕全屏与“…”。窗口窄时那些菜单收进“…”面板，面板里的菜单同样在顶层弹出。
- 所有菜单与弹出层（包括右键菜单、音量条与弹幕面板）都放在最上层，不被播放器、底栏或窗口裁切，每一项都点得到，Esc 关闭并还焦点。音量是点开后向上的竖条，可以拖动，也可以用滚轮。
- 播放器里不显示快捷键说明，也没有倍速输入框。“设置 › 键盘快捷键”按阅读器分组列出所有键，可以改键、恢复默认，两个动作用同一个键时指出冲突；按键处理和这页读同一份键位表。默认键位新增：R 在 1× 与自定义倍速之间切换，S 截图，D 开关弹幕，W 窗口全屏。
- “设置 › 阅读与播放”里编辑倍速列表（增、删、改；0.25—4，最多两位小数，不重复，自动排序，1× 固定保留），填自定义倍速与按住 → 的临时倍速；底栏与右键菜单用同一份列表。

**截图（AT-91）。** 视频的底栏有相机按钮（快捷键 S），漫画阅读器的底栏有“截图”按钮，框选区域后可“保存为截图”。保存后右下出现带缩略图的提示：打开文件夹、插入笔记、加入白板（选择白板）。视频截图默认带着画面上的字幕（主字幕与次字幕，A-92）。截图写进作品内容文件夹的“截图”目录；笔记里的截图是一个嵌入块，点击回到来源的时间或页。

**作品内容文件夹（AT-92、AT-102）。** 作品主页有“内容文件夹”一节：显示相对目录、各类文件的数量（含笔记），提供打开、按当前标题重命名；文件夹按条目与“未分类”放，见 3.8。“设置 › 常规”的数据位置里多了一个分区 `works`，与其他分区一样可以改位置，迁移时随之移动。

**弹幕（AT-94）。**
- 底栏的弹幕按钮开关弹幕，旁边的小箭头打开弹幕面板：当前剧集与匹配方式、偏移微调、刷新、重新选择、搜索（番剧名与集数）。作品没有关联 Bangumi、第一次需要匹配时，面板先问是否允许把文件的名称、指纹、大小与时长发给弹弹play；回答“不允许”后只有用户自己输入的搜索会联网。
- 弹幕层覆盖画面所在的区域，在字幕与底栏之下，随窗口大小、屏幕全屏与窗口全屏调整。没有可用凭据、没有匹配、网络失败、限流等情形都在面板里用中文说明原因，不静默无弹幕。
- “设置 › 弹幕”：开关、不透明度、字号、速度、“弹幕速度跟随倍速”（默认开）、显示区域（1/4、1/2、3/4、全屏）、滚动/顶部/底部/彩色、相似合并、屏蔽词与正则、来源开关、简繁转换、截图是否带弹幕、自己的凭据（覆盖内置的一份）与清除缓存。每处显示弹幕的地方都有“弹幕来自弹弹play开放弹幕网络”。

**模型与 Agent（AT-95—AT-97）。**
- “设置 › 模型”里每个连接的每个模型都有配置：上下文窗口、最大输出、输入类型、能力、推理等级，在添加与编辑的弹窗里改（见 3.8）；“测试连接”逐项显示结果并保存，失败时给出原因与解决办法。
- “设置 › 智能体”有步数与时长上限（默认 24 步、10 分钟）和调用追踪的保留设置（完整或只记大小，保留天数与上限，一键清除）。
- “设置 › 使用记录”的每次运行和对话里每条回复的“查看调用记录”打开同一个时间线对话框：左边按步骤列出模型请求、工具调用与上下文压缩，右边分页显示所选项的上下文、请求、响应与计时，可以复制为 JSON。

**粗剪（AT-98）。** 时间轴在有帧时间表时画出关键帧刻度，可以跳到上一个、下一个关键帧，切点按设置吸附到关键帧；导出面板选择音轨与字幕轨、合并导出或每段单独导出、合并时是否写章节，默认位置是作品内容文件夹的“粗剪”目录；导出详情显示实际执行的 FFmpeg 参数。

### 3.8 第三轮试用反馈后的界面（2026-10-10）

2026-10-10 用户试用后提出 13 条反馈，决定见 A-85—A-93，验收见 AT-99—AT-109。本节是返工后界面的文字正本；与 3.5—3.7 冲突时以本节为准。

**打开前的核对（AT-99）。** 书架、总览、作品主页、左栏“已打开”、“继续”、笔记的来源跳转、对话绑定的资源、模式切换与后退前进，都经过同一个入口：先问主进程这个资源能不能打开。不能打开时页面不变、不进阅读器，弹出一个提示框：
- 文件在所有资源库位置之外：写明文件所在的文件夹（不知道时说明可以用“重新定位…”选一个文件），按钮是“把所在文件夹加为资源库位置”“查看笔记与记录”“关闭”；
- 文件不在资源库位置里了（移动、改名、删除，或位置所在的磁盘没有连上）：写明原来的位置，按钮是“重新定位…”“查看笔记与记录”“关闭”；

- 正在看的资源所在的资源库位置被移除时，阅读器关闭并提示，左栏“已打开”里去掉这些资源，会话与进度保留；
- 书架与总览照常列出这些作品，用户内容找得到。

**删除条目与“未归入作品”（AT-101）。** 总览与三个媒介页的卡片菜单、作品主页的“更多”都有“删除条目…”。确认弹窗先写明“删除条目只去掉作品记录和来自在线条目的资料，你的文件和你写下的内容都留着”，再分“会删除”“会保留”两栏逐项写数量，最后写“不能撤销；文件不会删除，仍在资源库里”。删除后资源列在书架与总览末尾的“未归入作品”一组里：卡片可以打开，菜单有“归入作品…”与“匹配条目…”（为它新建作品后关联）；扫描不会自动把它们重新分组。作品级的笔记、作品会话与作品词典带着删除前的标题，在“设置 › 记录”与词典里找得到。

**用户内容文件夹与笔记文件（AT-102）。** 作品主页“内容文件夹”一节与设置里的位置页说明的是同一个结构：关联了条目的资源在 `<媒介>/<条目名>/`，同一条目的多个资源共用；没有关联条目的资源在 `未分类/<资源文件名>/`；子文件夹是截图、录音、粗剪、导出、笔记。每条属于某个资源或作品的笔记在“笔记”里有一个 Markdown 文件，开头写来源与“由 MANGA 生成，在这里修改不会写回应用”；改标题时文件改名，删除笔记时删文件。关联、取消关联、删除条目、归入作品时文件跟着移动，同名文件不覆盖（加序号）。升级后第一次启动时，已有的文件与笔记在后台按这些规则重排，界面照常可用，中途退出下次接着做。

**窗口按钮与窗口全屏的拖动（AT-105）。**
- 最小化、最大化（最大化时是还原）、关闭由应用绘制，在右栏顶部的最右侧；右栏隐藏时在主面板顶部；macOS 保留系统的红绿灯，页面不画这三个按钮。颜色来自主题 token：普通、悬停、按下各一套，关闭按钮悬停时用危险色，深浅主题与沉浸状态各一套。
- 窗口全屏与屏幕全屏时按钮和栏顶一起移出画面，指针移到上沿栏顶浮出时它们跟着出现。
- 窗口全屏时顶部留一条约 8 px、看不见的拖动条：按住拖动能移动窗口，双击切换最大化；它下面约 16 px 是浮出区，指针进入时栏顶浮出；快速甩到上沿、指针没有在浮出区里停留时，页面被指针离开的位置在上沿附近也触发浮出。浮出的栏顶空白处同样可以拖动，按钮不能。
- 代价（Q-32）：悬停最大化按钮时不再弹出 Windows 11 的贴靠布局；拖到屏幕边缘、Win+方向键、Win+Z 仍可贴靠。

**播放器（AT-106—AT-109）。**
- 字幕只有一个按钮。菜单分“主字幕”与“次字幕（显示在主字幕下方）”两组，各自单选、各有“关闭”，方向键上下可以从一组走到另一组，Home、End 到头尾；只有一条字幕轨或没有能做次字幕的轨道时，只有“主字幕”一组，不显示组标题；窄窗收进“…”时也只有这一个入口。
- 播放结束时底栏保持显示；结束提示（“重播”）、播放状态与健康提示、漫画读到最后的提示，在窗口全屏与屏幕全屏下按底栏高度抬高、层级在底栏之上，浮出的栏顶也不会盖住它们；漫画的页码输入、框选截图的按钮与阅读设置面板同样在三种状态下做命中测试。
- “设置 › 弹幕”的“弹幕速度跟随倍速”关闭时，2× 播放时滚动弹幕在屏幕上每秒移动的距离与 1× 相同，顶部与底部弹幕停留的时间也不变。
- 截图默认带字幕：ASS 字幕按视频的原始分辨率重画当前时刻，文本字幕按当前字幕样式画，位置相对画面、不受底栏抬高的影响；“设置 › 阅读与播放”的“截图带字幕”可以关闭，关闭后元数据仍记着当时显示的字幕文本，并注明没有合成。

**删除对话（AT-103）。** “设置 › 记录”的“对话”列出全部对话（全局、资源、作品、项目），每项显示标题、所属、轮数与最后时间；可以按模式、类型、时间筛选，按标题搜索；删除一个、多选删除、删除全部都先确认，确认框写明删除的范围（运行、消息、工具事件、调用追踪、检查点、冻结的材料），Agent 写下的笔记等内容不删；确认框还写明，删除只作用于现在的资料库，升级前应用复制的数据库副本（文件名带 premigrate，不含调用追踪）里还有当时的对话，删除对话不会改动它。右栏正显示被删的对话时换成新对话；有任务还在进行的对话不删，先停止任务。

**模型弹窗（AT-104）。** “设置 › 模型”页上方是“添加模型”，每个连接的“编辑”打开同一个弹窗，页面上没有常驻的表单。弹窗分“连接”与“模型能力”两组，错误显示在对应的字段旁、弹窗不关；编辑时密钥框留空表示不改；保存后可以直接“测试连接”，结果同时显示在弹窗与列表里；有未保存的修改时关闭弹窗、删除连接都要确认。列表里的用途、协议、运行时显示中文名称。

**文案（AT-100）。** 页面标题与左栏导航一致（总览、小说、漫画、动漫），书架状态、搜索、空状态、返回与话数单位按媒介措辞；界面上不显示内部标识（类别、用途、协议、运行时都经过中文名称）；没有“导入文件”“标题栏”“托管”这类已取消功能的说法。检查随 `verify` 运行：没人用的文案键、重复的键、固定的已取消说法、把内部标识原样显示、渲染进程里文案目录之外的中文，都使检查失败。

## 4. 信息架构

### 4.1 观测者导航

最近 → 资源库 → 小说/漫画/动画 → 收藏与进度 → 记录 → 搜索。

资源详情展示作品与版本、文件可用状态、卷章/集、最后位置、相关记录和引用。进度以用户能理解的章节、页、时间和完成状态显示。

阅读页首屏以资源为单位显示有界列表，同一本书的多个修订不重复占位。全库书名搜索支持继续加载，后续页沿用查询条件，总数始终表示完整匹配集。打开结果、保存阅读偏好等无关刷新保留已加载列表；资料库快照变化时重置首屏与搜索框，避免界面条件和结果不一致。分页由 `tests/shell/shelf.test.tsx` 与 `tests/library/works.test.ts` 守护，同规模性能见[执行状态](../delivery/status.md#验证基线)。

### 4.2 造物主导航

项目 → 材料 → 笔记 → 白板 → 思维导图 → 文案 → 粗剪。

项目首页展示目标、最近对象、材料来源、未处理记录与任务。个人资源可以从材料入口加入，已有笔记默认以引用方式加入项目。

### 4.3 Agent 主页面

全局导航提供独立“Agent”入口（界面名“对话”）；对话页不显示右栏，结构见 [3.5](#35-人工反馈后的界面结构2026-10-06)。主面板包含会话列表、消息、已选材料、文本/语音输入、任务进度、工具结果与停止入口。空会话展示可执行能力与连接设置入口；未交付模块不伪装成可用工具。

全局 Agent 入口与资源/工程右侧助手复用运行和业务服务；展示同一会话时共享任务身份，各资源/工程会话之间独立保存上下文、材料、环境和任务关联，不沿用一个全局会话冒充隔离。切换展示位置不复制任务、不重新提交请求，也不更改任务材料或目标版本。用户可核对工具输入摘要、执行结果、生成对象和来源，用同一页面验证已接入功能。诊断信息按需展开，凭据始终隐藏。

### 4.4 首次配置与资源总览

首次启动先展示当前通道（开发/正式）、数据根目录及资源/工程默认目录；默认使用系统“文档”已解析位置下的 MANGA 子目录，不拼写用户路径。用户可逐类选择位置，再配置文本/转录连接、模型与常用录音偏好；在线配置允许跳过，完成后都能在设置修改。

“资源总览”是独立页面，汇总小说/漫画/视频、项目/笔记/剪辑、附件/录音、下载、备份和可再生缓存。展示类别、数量、所在位置、索引或托管方式、占用与可用状态，支持筛选、打开、定位和修复。未安装模块的数据保留可读状态。磁盘扫描异步进行且可取消；资源失联时保留条目。UI 与 Agent 查询相同目录和资源服务，密钥等私密配置不进入总览。

### 4.5 设置

设置按用户任务组织为：外观与阅读、声音与录音、AI 功能与模型、模块、资源与存储、备份与导出、快捷键。设置是独立界面，分组为基础设置、Agent 能力、记录、日志，见 [3.5](#35-人工反馈后的界面结构2026-10-06)；下文各项内容归入对应分组。

AI 设置明确提供 API key、base URI、协议类型、模型 ID、超时和适用的生成参数。LLM、Embedding、ASR 独立绑定模型、连接和凭据并分别测试能力，可显式选择同一服务，但不自动继承另一用途配置；兼容服务不支持模型列表时允许手动填写。显示归一化后的请求基址和连接错误，密钥仅支持受控输入/替换与清除，不能回显到状态快照。资源与存储设置列出所有应用生成内容的位置、用途与迁移入口，迁移前展示范围，结束后验证并提供恢复。

声音与录音设置提供“保留音频/不保留音频”，说明后者仅为处理暂存，完成后仍可查看文本与来源，音频清理后无法回放。采集界面显示本次选择，改变偏好不追溯清理旧录音；初始默认及失败/取消清理时机按 Q-05 定稿。

## 5. 页面上下文交互

### 5.1 上下文栏

Agent 顶部用材料卡片显示当前准备使用的内容，例如：

- 《某小说》第二章，已选 128 字。
- 第 4 集，12:30，字幕范围 12:20—12:40。
- 当前漫画第 18 页，选中一个画面区域。
- 项目“角色关系整理”，已加入 3 条笔记。

用户可展开查看来源范围、移除某项材料或固定材料。没有截图/OCR/字幕时，界面如实显示可用信息，不以“已理解画面”代替实际提取状态。

### 5.2 跟随焦点与固定任务

默认准备区域跟随当前焦点，但发送任务时固定一次上下文。任务运行中切换页面，显示“此任务仍使用发送时的材料”；下一次消息是否改用当前焦点，由新的上下文栏明确呈现。

固定材料会持续出现在后续输入准备区，用户可以解除。切换项目时提示会话范围变化，既有任务保持原范围，不把其他项目的材料静默加入。

### 5.3 结果的落点

Agent 创建结果后展示对象卡片和位置，例如“已保存到个人笔记”或“已加入项目材料”。修改对象时显示目标名称、差异入口与撤销；目标版本变化则保留建议稿并提供比较。

## 6. 工作流 A：导入、阅读与带来源笔记

1. 用户选择文件或目录，导入面板展示识别结果、资源类型、重复项与失败项。
2. 默认索引原位置，托管复制作为明确选项；目录导入可以取消并保留已成功条目。
3. 打开小说后展示目录、进度、阅读设置和查找；正文选区触发轻量操作栏。
4. 选择“记录”后打开就近输入区域，显示来源片段和保存范围。
5. 输入正文或开始语音记录；保存时展示“保存中/已保存”，完成后提供笔记入口。
6. 从笔记点击来源，定位到原文并突出目标；用户可返回原来的笔记位置。

空库显示“添加资源库位置”入口和本地使用说明。没有 AI 配置时仍可阅读和创建人工记录，智能功能入口说明所需配置。

按 A-47、A-48、A-50：第 1、2 步在设置的“资源库”页进行（添加资源库位置并后台扫描）；点击作品先进入作品主页，再从“阅读/观看”打开；第 3—5 步的记录在右栏输入框完成，选区作为引用标签带入；资源库完全为空时应用打开到设置的“资源库”页。

## 7. 工作流 B：口述感想与异步整理

```mermaid
flowchart LR
    A[主动开始录音] --> B[采集声音并记录位置事件]
    B --> C[按保留选择暂存或保存音频]
    C --> H[本地筛选人声并保留原时间映射]
    H --> D[分块上传 ASR 并保存原文与来源]
    H --> I[无人声则结束且不上传]
    D --> E[可选 AI 整理]
    E --> F[带来源的可编辑笔记]
    D --> G[仅保留原文]
    D --> J[不保留模式完成临时音频清理]
```

### 7.1 采集界面

- 初次使用选择麦克风，并清楚显示当前输入设备。
- 同时提供按住录音与切换录音模式。按住模式松开结束；丢失键抬起、失焦或设备失联时有明确结束/恢复处理，避免隐蔽持续采集。
- 录音时同时显示“正在录音”文字、提示灯、持续时间、输入活动和停止入口；波形不能替代真实状态。
- 后台录音显示悬浮框，含文字、提示灯、时长和停止入口；设置可调整默认出现位置与大小，支持移动/缩放，跨显示器/DPI 或屏幕断开后恢复到可见范围。悬浮框订阅同一采集会话，关闭主页面不产生第二个录音任务。
- 播放器可按设置在录音时降低音量或暂停；变化反馈明确，结束后恢复原设置。
- 用户切换页面或资源时继续记录位置事件，录音的来源不会被最后打开页面覆盖。

### 7.2 整理界面

状态区分“音频已暂存/已保存”“正在筛选人声”“上传/转录进度”“原文可用”“正在整理”“笔记已保存”以及“音频待清理/已清理”。长录音可查看分块完成与失败状态，全程无人声显示没有可转录人声且未上传。用户可以在整理期间查看已经保存的原文和来源。

笔记同时保留原文入口、整理稿、引用位置和可选录音回放。专有名词修改可以保存到项目术语表，但只有用户确认的修改才成为术语。

以消息气泡或分段进度条展示语音区间、转录文本与来源，用户可快速浏览、选择片段、跳到录音当时的小说位置/漫画页/动画时间；音频实际可用时提供对应区间回放。展示原始时间间隔与已筛除区间，不能让压缩后的连续进度误导来源时间。无音频时保留文本和跳转入口，明确无法回放；仅有粗粒度定位时显示待校准，不伪装逐句同步。分段选择、回放、来源跳转都提供键盘与可读标签，进度/失败状态不只靠颜色。

### 7.3 失败与取消

| 情况 | 显示与恢复 |
| --- | --- |
| 麦克风拒绝访问/不存在 | 显示设备问题与设置入口，不显示虚假的录音计时 |
| 外放对白被误收录 | 允许修改原文/删除片段，提供耳机、降低播放音量和采集设置入口 |
| ASR 失败 | 保留位置和已完成文本，显示音频实际保留/暂存状态；音频可用时重试，否则提示重新录制或手动输入 |
| 整理失败 | 原文可用，允许稍后重试整理 |
| 用户取消处理 | 保留已保存记录，显示已停止阶段；临时音频按明确策略显示恢复/清理入口，不假称已删除 |
| 临时音频清理失败 | 文本和来源继续可读，明确待清理并可重试，不提供虚假的已清理状态 |
| 来源定位不准 | 用户调整来源点/范围，保存修订记录 |

回声消除有设备与实现差异，交互上不使用“保证只录到本人”之类绝对表述。

录音的采集、人声筛选、音频保留选项、分段回顾与三种媒介的来源映射已实现（A-46）；设备项的人工检查见[用户待办](../../USER-ACTIONS.md#checks)。

## 8. 工作流 C：素材整理与互嵌

1. 从记录列表选择材料，加入项目；默认创建引用关系。
2. 拖到白板上生成来源卡片，显示标题、摘要和来源标记。
3. 对卡片进行移动、分组、连线或打开源内容。
4. 将材料加入思维导图节点，调整层级与顺序。
5. 在笔记中嵌入白板、导图或局部节点，通过展开和跳转查看。

嵌入卡片的菜单明确区分“打开源内容”“编辑源内容”“固定为快照”“复制一份”。编辑源内容时标注可能在其他引用位置同步更新。

循环嵌入或超出展开深度时显示可跳转卡片；模块停用时显示可读预览和启用入口。无效引用提供原信息与修复操作，不能仅留下空白区域。

## 9. 工作流 D：文案与资料搜寻

### 9.1 资料搜寻

用户输入检索意图，先查看本地材料；需要外部信息时启用已配置的检索连接。结果显示标题、来源、获取时间和片段，可以加入项目、建立引用或继续阅读。

保存材料时允许选择只记录链接、保留正文片段或保存允许获取的本地快照。来源版本变化后保留已有快照，并提供更新为新版本的选项。

### 9.2 文案生成与修改

用户选择目标文档/选区、使用材料与修改意图，Agent 返回提纲、候选稿或差异。用户可以整段采用、局部采用、继续修改或撤销。

文案界面保留材料引用。缺少来源支持的陈述以待核实内容呈现，生成文本不冒充原始引文。

原文被编辑时，旧候选稿进入冲突比较，允许作为新草稿保存。自动润色不能覆盖中文输入法正在组合的内容。

## 10. 工作流 E：视频粗剪

### 10.1 编辑

用户从播放器标记区间，或从笔记引用中添加片段。粗剪页面以片段列表/单序列时间轴展示来源、请求区间和顺序，提供拖动排序、区间调整和连续预览。

### 10.2 导出前预览

导出面板展示输出位置、容器、流选择、兼容状态、每段实际切点和预计处理方式。实际区间存在偏移时以时间差说明，例如“实际起点比标记早 0.38 秒”，具体数值来自后端探测。

不兼容时列出导致失败的素材和原因，允许调整片段或导出设置。首版仅支持编码/容器一致且流参数兼容的无转码方案，不能静默转码。

导出面板还让用户选择要保留的音轨与字幕轨，选择“合并成一个文件”或“每段单独一个文件”，合并时可以把每个片段写成一个章节；默认输出到作品内容文件夹的“粗剪”目录，可以改。导出详情里显示实际执行的 FFmpeg 参数（本机路径经脱敏）。多片段合并的字幕（ASS）不带内嵌字体，见执行状态的限制。

### 10.3 导出任务

启动后进入任务列表，提供进度、停止和结果入口。取消或失败保留编辑项目，并清楚处理临时输出。完成后显示实际文件与来源映射，原始素材不被导出操作覆盖。

## 11. 工作流 F：模块管理

模块页面按功能显示状态、提供能力、依赖、配置和存储占用。用户关心的名称为“小说阅读”“语音记录”“文案辅助”等，技术标识放在详情。

功能中心分别提供“隐藏界面、停用功能、卸载代码、清理数据”。一个用户功能可以映射多个模块，共享依赖仅在没有其他消费者时停用；关闭漫画阅读器后漫画文件、作品资料、进度和引用仍可管理。需要重启时显示待生效状态，不提前报告停用成功。

“动漫资料”首批为 Bangumi，设置按来源管理连接，提供单源、回退、多源搜索与字段合并方式，并显示字段来源和用户锁定值。“下载管理”首批使用 BitTorrent，随获取组合启用，展示计划中的来源、文件、目标目录和任务阶段；文件已下载与已入库分别显示。没有安装对应能力时，基础本地流程仍然完整。

停用操作先展示受影响项目：活动视图、进行中的任务、依赖模块，以及数据将保持保留。已存在授权足以完成停用时直接按方案执行；存在未处理草稿或必须选择的任务处理方式时，再给出具体选项。

停用成功后入口与工具同步更新；引用保留预览。重新启用后，重新注册服务和恢复可处理任务。卸载代码与清理数据为两个独立操作。

Profile 是运行装配方案，观测者/造物主模式只是布局。切换 Profile 需要依赖与任务影响检查；配置解析失败时可回到上次有效配置或恢复模式。具体产品行为见[组合方案](composable-ai-native-architecture.md)，换源与下载流程见[外部扩展](external-providers-and-acquisition.md)。

## 12. 工作流 G：备份、导出与引用修复

### 12.1 备份与导出

完整备份说明数据库、附件和外部媒体的覆盖范围。资料包导出则展示选择对象、依赖引用、是否包含媒体/录音和预计大小。

导入先预览对象数量、已有 ID 冲突、缺失模块和缺失媒体，再提交。冲突选项不默认覆盖用户现有内容。

### 12.2 修复来源

用户从失效卡片进入修复，选择候选文件或重新指定位置。系统展示内容校验结果与候选定位，用户确认后更新引用关系，并保留原锚点与修复记录。

同名但内容不同的文件不能显示为“已自动修复”。源对象被永久删除时卡片保留必要描述和删除状态。

## 13. 状态、反馈与通知

| 状态 | 用户能看到的反馈 |
| --- | --- |
| 正在保存 | 保存状态，必要时退出前等待或提示未完成内容 |
| 已保存 | 已持久化确认，重新打开能恢复 |
| 模型未配置 | 缺少能力与配置入口，已有内容继续可用 |
| 正在处理 | 明确任务阶段，真实可用进度，停止入口 |
| 等待输入 | 说明需要用户决定的具体事项 |
| 失败 | 保留结果与原始材料，显示可重试或修复操作 |
| 取消请求中 | 表明正在停止，不提前显示完全结束 |
| 已取消/已完成 | 与执行器确认状态一致 |

阅读与观看期间避免频繁弹出任务消息。普通后台处理只更新状态，完成、失败或需要用户操作时提供适度提示。提示可点击返回相关任务，不改变当前内容焦点。

首版中文文案集中使用稳定消息键，参数插值与日期/数字由本地化层处理，不拼接中文句子。后续语言可新增资源并配置回退，内容语言和界面语言分开；测试语言只用于检查扩展性，不代表额外发布承诺。

## 14. 交互验收清单

- 全部核心流程可使用键盘完成；输入法组合不被命令打断。
- 在最小窗口、标准缩放和高 DPI 下，正文与主要操作没有不可达区域。
- 左右栏和顶部壳隐藏后均能恢复；任务与录音状态有可发现入口。
- 窄长、宽屏和矮窗切换中，悬浮侧栏可经悬停/点击/键盘操作并退出；模式菜单、系统窗口控制与正文选区互不干扰，主面板空间随辅助区域收起而释放。
- 模式、标签和项目切换不会丢失已确认保存的内容，运行中任务目标不漂移。
- 同一来源从笔记、白板、导图和粗剪跳转具有一致行为。
- 引用、快照和复制的区别通过可见操作表达。
- 停用模块、断网、缺失文件和模型错误均有可继续工作的路径。

对应的场景测试、样本和状态记录见[交付阶段与验收计划](../delivery/roadmap-and-acceptance.md)。
