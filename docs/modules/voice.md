## 1. 责任与依赖

拥有录音会话、位置事件、人声筛选、分块转录、转录片段与来源映射、整理草稿、作品术语表和音频保留策略。不拥有笔记（草稿被接受时才经笔记服务创建）和资源/进度身份。Feature `voice`；Facet `service`/`ui`；硬依赖 `manga.library`；转录需要一个 ASR 连接，整理需要一个文本模型连接，缺少连接时录音与原文照常保存并显示“等待连接”。

**管线：** 渲染进程用麦克风采集 → AudioWorklet 转 16 kHz 单声道 16-bit PCM，按序号分块发给主进程（`capture.append`，重复块忽略、缺块补静音、丢尾按渲染进程计数补齐）；事件（开始、翻页、选区、暂停/继续、倍速、跳转、资源/集切换、停止）带音频时钟偏移（从第一个音频样本起算，不含权限等待）。录音时由独立 worker 里的 Silero VAD（ONNX，onnxruntime-web WASM，MIT）增量筛选，两侧各留 300 ms 余量；超过 120 s 的滞后会放弃实时筛选，停止后改为对文件做一次完整筛选（约 94× 实时）。语音段按 1.5 s 内合并、单块不超过 30 s、在静音点切分，块键由采集偏移确定，重跑不会重复提交；全程无人声不上传并明确提示。每块转录前后都持久化，已转录的块不重发，限流退避、重复失败标记 failed 而保留音频，认证错误立即停止并说明原因。

## 2. 数据与公开能力

- 数据：`capture_sessions`（模式、保留策略、音频状态 staged/retained/cleaned/none、阶段、时长、VAD 摘要、错误）、`capture_events`（偏移、原因、资源、修订、位置、播放状态与倍速）、`transcript_segments`（块键、起止、原文、修订文本、状态、精度、是否校准、锚点列表、尝试次数）、`capture_drafts`（整理草稿、用户编辑、生成的笔记 ID）、`work_terms`（角色/术语纠正）。阶段：recording → recorded → filtering → awaiting_asr → transcribing → done，另有 pending、no_speech、failed、cancelled；每步写库后才进入下一步，中断后的下一次运行从上次状态继续，应用中途退出的录音启动时恢复为已停止并可转录。
- 来源映射：`mapInterval` 按事件把每个录音区间映射为锚点：小说为文本位置，漫画为页（及选区），动画为原件时间区间；翻页、选区变化、跳转、资源或集切换开一个新锚点，暂停不开新锚点（时钟继续走而来源时间静止，录音区间长度保持真实，来源范围保持实际覆盖范围）；ASR 返回时间戳时按句拆分各自带锚点，否则整块作为一个“粗定位、待校准”片段，用户可手工指定并标记已校准；ASR 晚到时仍按请求时的位置，不按到达时的位置。
- 保留：`capture.retain` 选择保留（Opus/WebM 存附件，工作副本在文本与映射都已写库后才删除）或不保留（暂存 PCM 在同样条件后清理）；清理失败如实显示而不是显示已完成；失败或取消时暂存音频保留到重试成功或用户明确丢弃（Q-05）。
- 整理：`capture.organize` 把已存转录交给文本模型生成草稿，用户编辑始终保留且不会被后来的重试覆盖，失败只记录并可重试；`acceptDraft` 以用户确认的文本、每处位置一个锚点创建一次笔记；模块停用后迟到的草稿被丢弃。
- 设置：`holdKey`（默认 F9，只在应用内有效，不是全局快捷键）、`toggleKey`（默认 F8）、`retention`（默认 keep）、`duckPlayback`（默认 lower：录音期间视频降到约 30%，可改暂停或不变）、`boundaryMarginMs`（300）、悬浮框位置与大小。
- 错误：设备拒绝/缺失不创建会话也不起时钟；设备丢失、窗口失焦、按键丢失、停用、关闭都带原因停止并保存已收到的音频；存储失败结束录音并说明原因；越权/不属于同一资源的修订被拒绝。

## 3. Agent 与界面

界面（M2 返工后）：录音入口在右栏输入框的麦克风（单击切换录音，按住说话；阅读/播放页不再有录音按钮）与右栏收起时的悬浮胶囊，显示录音文字、提示灯、时长和真实采集状态；标题栏只留紧凑录音指示（含输入电平，窄窗下缩小），标题栏不再有回顾按钮；录音按作品管理，回顾与回放、重试转写、清理待处理音频在设置的“记录”页（见[笔记模块](notes.md)）。以下为沿用的能力：录音期间的悬浮框（独立小窗，始终可达：保存的位置不在任何屏幕上时回到主屏右上角，大小有上下限）、回顾面板（消息气泡/分段进度条、每段来源卡、跳回来源、手工校准、术语表）、整理草稿与“生成笔记”。Agent 不能启动录音或读取原始音频；整理由用户触发，使用所选文本连接。录音文字是用户口述链路，与媒体自身转写分开。

## 4. 生命周期与兼容

停用：正在进行的录音先保存再停止，迟到的转录/草稿结果被丢弃，worker 与句柄随代次失效；已存的录音、转录和映射保留。重新启用后可继续转录未完成的会话。资料包导出包含会话、事件、片段、草稿与术语（音频附件按保留状态）；回导按冲突决策处理，不删除用户已有内容。数据由 v7 迁移追加，旧录音（M0/M1a 的 `capture.save`）保持可回放。

## 5. 验证与未决

自动：`tests/voice`（采集服务、位置映射、VAD 分段与 worker、分块、转录管线、回顾与录音界面、30 分钟时间线）、`tests/helpers/voice.ts` 合成语音与噪声；真实契约 `tests/real/asr-contract.test.ts`（`MANGA_LIVE_ASR=1`，只发合成语音，不进 CI）；打包烟测 voice 阶段用 Chromium 假采集设备播放合成语音。限制：外放误收录、耳机对照、设备断开、硬件采集延迟和多显示器悬浮框只能人工（H-M2-06）；整理的真实 LLM 调用与视觉/OCR 未授权。未决：Q-05（默认值）、Q-11（媒体会话休眠预算）。
