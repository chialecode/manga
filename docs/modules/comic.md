## 1. 责任与依赖

拥有漫画页面清单（页身份、顺序、尺寸、哈希、是否可读）、页面显示句柄与缩略图，以及“页/区域”定位的解析。不拥有作品与资源身份、进度、笔记和封面选择（归资料库）。Feature `comic`；Facet `service`/`ui`；硬依赖 `manga.library`；不依赖 AI、网络或元数据来源。

支持来源：PNG/JPEG/WebP/GIF/AVIF/BMP/TIFF 目录（子目录是独立章节）、CBZ/ZIP、PDF（页即图片，渲染交给 PDF.js）、EPUB 漫画（spine 每页是一张图）、MOBI/AZW3 的图片记录。页序用自然排序，非连续编号与重复名保留；`ComicInfo.xml` 只读取标题、卷章等字段（≤ 1 MiB）。图片在导入时逐页解码检查，坏页保留在清单中标为不可读，不使整本失败。页面超过 4096 px 边或 2400 万像素时，显示版本由 sharp 缩放，原图只在“原图”变体下提供；非浏览器格式在显示时转换。加密的压缩包、EPUB、MOBI 一律以 `UNSUPPORTED_FORMAT` 拒绝；漫画路径下的 PDF 不因含 `/Encrypt` 字样而预先拒绝（只设所有者密码的文件可以打开），需要打开密码的 PDF 由 PDF.js 报告后同样以 `UNSUPPORTED_FORMAT` 失败。

## 2. 数据与公开能力

- 数据：`resource_revisions.layout_json` 保存页 ID 序列与单位；缩略图是可重建缓存。修订指纹基于文件内容，同一文件再次导入识别为重复，内容变化产生新修订，旧锚点仍绑定旧修订。
- 定位：`ImageLocator`（页 ID + 可选归一化区域）；`resolveMediaLocator` 只把定位解析到它所属的修订，另一修订不会误解析。笔记和书签只能指向修订里真实存在的页（`assertLocatorFits`）。
- 命令：`comic.pages` 返回清单；`comic.pageHandle/pageHandles` 签发不透明的 `manga-media://` 句柄（渲染进程看不到路径），按页、变体（display/original/thumb）和最长边请求；`material.region` 为用户准备一张页面区域图作为任务材料，只留在短期暂存，发送时才冻结。句柄绑定模块代次、资源修订和会话，模块停用、会话关闭或 30 分钟过期后失效。
- 错误：越权 `SCOPE_DENIED`，格式不支持 `UNSUPPORTED_FORMAT`，模块在加载期间被关闭 `CANCELLED`，单页超过 256 MiB 拒绝。

## 3. Agent 与界面

Agent 通过 `material.region` 与阅读器选区取得图片材料；该命令仅所有者可用，任务不能自行取页面。界面：书架卡片（封面、状态、进度）、详情页、阅读器，包含从右到左/从左到右、单页/双页、长条滚动、缩放、铺满、自动翻页、页码与缩略图、页/区域选择记笔记、来源返回；默认方向为从右到左（可在设置中改）。键盘：方向键随阅读方向翻页（靠近下一页来向的那一侧为下一页），`+`/`-`/`0` 缩放，`F` 全屏，`Esc` 退出选区或全屏。窗口窄时右栏为浮层，主面板优先。

**页面尺寸与舞台（A-47 W1，AT-68）：** 阅读器根元素占满主面板并有确定高度，舞台（`.comic-stage`）的尺寸只由布局决定，与页面内容无关；页面尺寸 = 适配基准 × 缩放，基准由舞台的可用尺寸与页面的自然尺寸算出（适配整页取宽高较小的比例，适配宽度、适配高度各取其一），缩放范围 25%—400%。页面比舞台小时居中，比舞台大时舞台出现滚动条；适配整页时整页始终可见。舞台为经典滚动条预留位置（`scrollbar-gutter: stable`），测量时再减去滚动条占用的宽度（`offsetWidth − clientWidth`），否则适配宽度的高页会因滚动条出现而横向滚动（这是 AT-68 的真实窗口场景发现的缺陷）。长条模式不受缩放基准影响。

**工具栏：** 顶栏只有页码跳转、上一页/下一页、区域选择、全屏与“…”；底栏是标题、页码、页面滑块、适配方式（整页、宽度、高度、原始大小）与缩放（`−`、百分比、`+`，点百分比回到 100%）；单页/双页/长条、阅读方向、封面单独成页、自动翻页与翻页动画收进“…”面板，面板在矮窗里不被裁切。页/区域选区作为引用标签进入右栏输入框，页面里没有记笔记与录音按钮。

## 4. 生命周期与兼容

停用时递增模块代次，使全部页面句柄失效并取消该模块的后台任务；晚到的页面结果不留下可用句柄。启用后创建新的句柄生成。已导入的清单、进度和笔记保留；停用期间阅读入口移除，导出/备份仍包含漫画资源与锚点。旧 schema 数据由 v7 迁移追加列，不改写既有内容（`tests/library/schema-v7-migration.test.ts`）。

## 5. 验证与未决

自动：`tests/comic`、`tests/media`（句柄、范围请求、zip 池、缩略图）、`tests/reading/comic-model.test.ts`、`comic-reader.test.tsx`（含页面尺寸不变量与滚动条占位）、`tests/samples`；打包烟测 media 阶段用合成漫画样本驱动真实窗口；`rework` 阶段在宽窗、窄窗、矮窗各取适配整页/宽度/高度并依次缩放 100%/125%/200%/75%/50%，断言页面尺寸 = 基准 × 缩放（±1 px）、舞台尺寸不变、小于舞台时居中、大于舞台时可滚动、适配整页时整页可见且不出现横向滚动（AT-68）；悬浮胶囊在带底栏的页面（漫画页、播放器）停在右上角、标题栏之下，标题栏下的提示条让出这个角；窗口观察 `capsule-clear-of-controls` 在三种窗口尺寸下量它（含展开笔记框，漫画页另开框选工具量提示条上的按钮）不压住工具栏、提示条、底栏和播放器的任何按钮与滑块。真实库只读试验的聚合结论见交付报告（无文件名与路径）。未决：Q-12（阅读偏好默认值）；人工项 H-M2-01、H-M2-03；真实库中约 6% 的 PDF 只设所有者密码，现在可以打开；是否保持这一放宽由 A 审查确认。
