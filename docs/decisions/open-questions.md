## 3. 待决问题与推进边界

<a id="q-01"></a>
### Q-01：交付优先级

- 负责人：产品负责人；状态：本次已询问，待回复。
- 当前顺序：M1 小说/笔记/语音/Agent，M2 漫画/动画/元数据，M3 创作，M4 粗剪/下载。
- 截止：M1 范围锁定前。先维持评审稿，文档框架与公共契约设计继续；改变顺序需同步需求阶段、里程碑和验收映射。

<a id="q-02"></a>
### Q-02：基础技术偏好与选型

- 负责人：技术负责人；涉及明确用户偏好时由产品负责人补充。状态：本次已询问，待回复；技术验证尚未执行。
- 当前：界面/编辑基础、SQLite 驱动、包管理与构建工具、组合运行时在 M0 验证后定稿，不预选 React、Vue、Drizzle 或某个 Agent 框架。
- 截止：相应依赖进入正式工程前；依据 POC-05/06/07。可以继续契约与可替换原型，不宣称任一候选胜出。

<a id="q-03"></a>
### Q-03：数据目录与宿主运行边界

- 负责人：技术负责人；状态：待 POC-06/07。单用户与无需登录已确认，A-13 仍为技术假设。
- 截止：M0 结束。验证单写入、多窗口、异常退出与恢复；安装版/便携版及自定义数据目录策略由产品目标结合验证决定。

<a id="q-04"></a>
### Q-04：媒体样本与精确支持范围

- 负责人：产品负责人、技术负责人；状态：待样本与 POC-01/03。
- 需要：首批 TXT 编码/EPUB 特性、漫画大图、动画容器/编码/字幕、粗剪精度；按使用需求优先采样，不承诺全格式。
- 截止：M1 阅读实现和 M2/M4 发布范围定稿前。协议设计可继续，格式/性能声明须等真实验证。

<a id="q-05"></a>
### Q-05：语音策略与数据保留

- 负责人：产品负责人、技术负责人；状态：待 POC-02。
- 需要：录音按住/切换、媒体降音/暂停、首个 ASR 服务、原始录音保留/清理默认、定位误差与外放预期。
- 截止：M1 语音功能定稿前。原型先用明确临时配置，不能未经决定默认自动删除用户录音。

<a id="q-06"></a>
### Q-06：第三方插件执行形式

- 负责人：技术负责人；状态：待隔离验证。
- 截止：M4 开放第三方执行前；先落实可信内置/开发插件和可导出数据，不以 Node 子进程作为安全隔离证明。

<a id="q-07"></a>
### Q-07：首批真实元数据与下载提供者

- 负责人：产品负责人、适配器维护者；状态：待选择。
- 需要：优先站点、字段语言/冲突策略、授权资源来源、传输方式与使用限制。
- 截止：M2 元数据/M4 下载正式适配前。先按 POC-08/09 用可控假提供者和 HTTP 服务验证，不需要为文档治理提前决定全部站点。

<a id="q-08"></a>
### Q-08：视觉与发布语言范围

- 负责人：产品/设计负责人；状态：待原型评审。
- 已知：白灰粉简洁方向、三栏默认、输入法和可访问性。待定：具体 Token、首版主题数量、应用 UI 发布语言（中文/日文内容支持不等于日文 UI）。
- 截止：M1 视觉基线定稿前。现有数值仍为候选，主题数量与发布语言分别定稿。

<a id="q-09"></a>
### Q-09：仓库协作与公开发布

- 负责人：项目维护者；状态：部分已决定。用户于 2026-09-19 授权建立 `chialecode/manga`，确认单人维护的 PR/必需检查/0 审批 Ruleset，以及 GitBook 只准备配置暂不连接；见 [ADR-0002](0002-local-first-github.md)。安全报告采用 GitHub 私密漏洞报告入口。
- 仍需：许可证、对外贡献权利安排、产品发布签名与分发方式；GitBook 实际 Space、可见性和发布域名在决定接入时再提供。
- 截止：首次正式接收外部代码贡献或分发应用前确认相应权利和发布要求。当前已授权的 Git/CI 建设、本地设计与开发继续，不擅自选许可证或填虚构邮箱。

<a id="q-10"></a>
### Q-10：Game、云同步与协作

- 负责人：产品负责人；状态：vNext 待需求。
- 截止：启动对应功能设计前。首版不把它们作为隐式依赖；后续另写用户旅程、数据/权限模型和验收。

## 4. 收到决定后

在本文件写入原意、来源、日期和范围，更新相关 A/Q 状态；需要长期解释技术取舍时追加 ADR。随后同步产品/设计正本、阶段与验收映射，并执行文档检查。不能只把问题标为“已解决”而留下相互矛盾的正文。
