## 背景和候选

候选 A：自研 `packages/kernel`。候选 B：`MinimalActivator`（故意无屏障/无释放）。未做完整第三方微内核适配。

## 决定与理由

**推荐（仍为 proposed）**：继续验证自研 `packages/kernel` 候选；必要契约与维护成本验证后再决定正式采用。目标是 UI Facet、service 命令与解析 worker 走统一的有限授权与代次；停用撤销贡献并丢弃晚到解析。当前固定 scope 字符串不构成完整 actor/资源授权，布尔 UI 标志不证明真实 React 入口已随模块撤销。

实测理由：

- 50 次启停资源计数、IPC 取消/退出、UI 与假 Agent 同一命令、跨范围拒绝、阅读器停用后资料保留、假提供者换源后快照仍可读、下载模块停用后资源身份保留。
- 真实 Node 子进程解析 worker 支持取消、退出后请求失败、库停用后丢弃晚到结果。
- `MinimalActivator` 是门禁反例，用来证明检查能失败；不能当作公平对比后“kernel 胜出”的依据。

以上实验子集不能提升为完整产品能力。2026-09-19 [复核](../evidence/2026-09-19-m0-closure-review.md)补充确定性晚到结果拒绝及 worker 重新启用回归；有限授权、真实 UI Facet、维护成本与替换边界仍需 [M1a P1](../delivery/m1a-execution-plan.md)实证。

未做：第三方插件沙箱、不可信代码隔离、完整微内核替换。可信实验进程边界 ≠ 安全沙箱。

维护：契约演进以模块清单/epoch 拒绝旧句柄；复杂图变化允许重启并在界面写明生效状态。依赖版本由 `pnpm-lock.yaml` 与 `scripts/check-deps.mjs` 核查。

## 后果和实施

落选实验不得进入发行依赖。M1a 可以继续可逆候选集成与验证，正式交付前完成本 ADR 的技术定稿；开发 Agent 不代签用户决定。Q-06 的第三方执行形式仍按原截止点，不提前开放。
