## 文本 / EPUB

| 组合 | 状态 | 说明 |
| --- | --- | --- |
| UTF-8 + BOM TXT | 已验证支持 | 去 BOM，NFC，LF |
| 中文 / 日文 / emoji / ZWJ | 已验证支持 | Unicode 码点锚点 |
| 重复句 | 已验证支持 | 需 quote/prefix，不默默跳到第一处 |
| 长章 > 32,000 字符 | 解析/定位子集已验证 | `getResource` 返回全文；DOM 仅预览开头 8,000 字符，全文浏览/跨章选区尚未实现 |
| 手选非 UTF-8 实档 | 未验证 | 开发者先补合成编码样本与明确子特性，不要求用户提供私人原文才能测试 |
| 基础 EPUB 多章+插图标签 | 已验证支持 | 自研 zip+html 文本抽取 |
| 非法路径 / 超大条目 | 已验证拒绝 | 拒绝 |
| 复杂 CSS/加密/音频 EPUB | 未验证 | 未宣称 |
| MOBI / PDF | 未验证 | 已确认 M1b 目标；需解析器与固定/重排页、扫描/加密等子特性验证 |
