# M0 必要实机复测

核对日期：2026-09-19。已保留用户报告通过的微信输入法、美式键盘、100%/125%/150% 缩放，以及真实外接麦克风基础录音/保存/回放；见[实机反馈](2026-09-19-m0-device-followup.md)。这些记录属于当时版本。本轮仅复测实际受影响的交互，不要求重做全套；下一轮 React 界面稳定后再做对应短测。

## 1. 打开本轮原型

```powershell
./scripts/open-m0-package.ps1
```

脚本打开 `dist/latest-package.json` 指向的独立包。人工原型数据使用 `%LOCALAPPDATA%/MANGA-M0-review`，它是实验历史路径，不代表已满足正式产品 DATA-04 的全量可配置目录要求。不要用修复前仍打开的窗口判断本轮结果。

## 2. 可选短体验：回放与导出，约 2 分钟

1. 用户主动录一小段或选择已有原型录音，确认出现有限总时长；分别在播放前、播放中拖动进度，播放应从新位置继续推进。
2. 切到另一条录音，再切回来；播放中修改笔记并等待保存，播放器应保持可用，不一直显示加载状态。
3. 确认独立「导出录音」始终可找到。选择空文件名导出，原件应能播放；取消选择应准确反馈取消。导出不依赖原生三点菜单。
4. 关闭窗口后重新打开，已保存录音应能再次选择、播放和导出。

相同软件流程已在假麦克风独立包中自动验证；这里仅确认真实录音在本轮播放器上的体验。整段解码有 64 MiB PCM 限制，超限应给出错误且仍能导出原件；长录音策略是 M1b 开发任务。没有本次人工反馈不阻塞 M1a 基础实施。

## 3. 按块编辑的针对性短测，约 1 分钟

仅当使用本轮拆块/合并界面时执行：在当前块中文组合输入，按 Enter 完成候选后检查没有多余保存或清空；编辑后 Ctrl+Z/重做；拆为两块后修改其中一块、切到侧栏再回来，确认另一块不丢失；保存后重启检查两块内容。

本轮更改了按块编辑与保存边界，旧 textarea 人工通过记录不能完全覆盖新路径。完整结构操作撤销尚未实现，属于 M1b 新编辑器工作；不要据此要求用户继续尝试才能完成开发。三档缩放旧记录保留，新 React 最终界面再做一次短测。

| 项目 | 开发者必须先完成 | 后续必须人工参与的部分 |
