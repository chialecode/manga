# MANGA 核心产品原则

本文整理原文档已记录的用户确认方向，以及 2026-09-19 本次会话新增确认。它约束后续需求和实现；技术细节与细化排期仍按 [需求](../product/requirements.md)及 [决定台账](../decisions/open-questions.md)的状态处理。

## 长期承诺

| 原则 | 对开发的含义 | 需求/验收入口 |
| --- | --- | --- |
| 围绕二次元内容，贯通阅读观看、记录、素材与创作 | 按完整工作流判断成果；页面数量不是完成度 | READ、NOTE、CRE、CLIP；交付计划 |
| 本地优先，两种模式共享内容和记录 | 无 AI 可读可写；爱好者/创作者是工作区预设，不复制业务身份 | BASE-02、AT-01 |
| 稳定引用与来源可追溯 | 来源、位置、版本与用户记录保持关联，失败能定位和修复 | NOTE-02、DATA；AT-04、AT-18 |
| Agent 原生参与 | 每个业务模块有结构化状态与统一能力，UI 与 Agent 共享服务；可以关闭 Agent | BASE-01、CTX、AGENT；AT-09、AT-44 |
| 业务功能可拆卸、可替换、可独立装配 | 隐藏与停用不同；关闭阅读器不会删除文件和记录；基础服务按依赖保留有效实现 | BASE-03、PLUG；AT-21、AT-38 |
| 外部资料与下载可选 | 本地身份不绑定网站；多源按字段策略组合；后装下载不反向绑住本地库 | META、ACQ；AT-39—43 |
| 核心业务优先自主实现 | 自主掌握内容模型、引用、业务交互与协议；必要底层库经适配使用 | NFR-05、POC-07 |
| 设计错误从模型和边界修正 | 重构同步提供用户数据迁移与恢复，不靠隐式补丁维持矛盾 | DATA、NFR-02；AT-15、AT-48 |
| 简洁的白、灰、粉视觉与可收起辅助区域 | 内容是主面板，三栏是默认布局，输入与阅读可访问 | UI；AT-16 |

已确认技术方向为 TypeScript、Electron、monorepo。应用内语音记录、笔记/白板/导图引用与互嵌、创作搜寻/文案/粗剪、按 AI 任务配置模型属于既有方向；其格式、精度、首期深度和技术选型仍需按阶段验证。

## 首发基线

2026-09-19 用户明确确认：**本地单用户、基础功能无需登录、Windows 11 x64 首发；其他桌面系统后续独立验收。** 该确认不等于已经有 Windows 安装包，也不排除某个在线服务需要它自己的凭据。云同步、多用户和账户体系不隐含在首版范围内。

具体安装形式、支持格式、里程碑顺序和技术候选的决定位置见台账；不要从操作系统确认推导出这些细节也获确认。

## 新功能判断

新增功能先说明帮助谁完成什么工作、复用哪些内容/引用、无模型或停用后怎样继续、Agent 如何获得状态与执行能力，以及所属阶段和验收。当前阶段不承诺的功能保留明确入口与状态，不能以空页面冒充可用。

更改这些长期承诺时记录明确产品决定，并同步需求、设计与验收。已授权的新决定可以替换旧方向，不能以本文件阻止用户调整产品。
